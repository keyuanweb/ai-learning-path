# 环境搭建

本阶段安装 SDD 工作流所需的核心工具链，包括 GitHub Spec Kit 和 sdd-flow 插件。

---

## 1. GitHub Spec Kit（主工具）

[GitHub Spec Kit](https://github.com/github/spec-kit) 是 GitHub 开源的 SDD 工具包，提供 CLI 命令生成规范、计划、任务，配合 AI 编码助手使用。

### 安装

```bash
# 方式一：uvx 直接运行（推荐，无需持久安装）
uvx --from git+https://github.com/github/spec-kit.git specify init <项目名>

# 方式二：pipx 持久安装
pipx install git+https://github.com/github/spec-kit.git
specify init <项目名>

# 方式三：在现有项目目录中初始化
cd my-project
specify init --here
```

### 验证

```bash
# 初始化后检查目录结构
ls -la .specify/
# 应看到 memory/ scripts/ templates/ 三个子目录

ls -la .github/agents/
# 应看到 AI Agent 配置文件
```

### 项目结构

初始化后生成的文件：

```
project/
├── .specify/
│   ├── memory/
│   │   └── constitution.md        # 项目宪法（由 /speckit.constitution 生成）
│   ├── scripts/
│   │   └── bash/                   # 辅助脚本
│   └── templates/                  # plan/spec/tasks 模板
├── specs/                          # 功能规范目录（每个 feature 一个子目录）
└── .github/agents/                 # AI Agent 提示词
```

## 2. sdd-flow 插件（Claude Code 集成）

[sdd-flow](https://github.com/nushey/sdd-flow) 是 Claude Code 的 SDD 插件，提供多 Agent 阶段门控流水线。

### 前置条件

```bash
# 确认 Git + GitHub CLI 已安装并认证
gh --version
gh auth status

# 确认 Claude Code 已安装
claude --version
```

### 安装

```bash
# 在 Claude Code 中执行
/plugin marketplace add nushey/sdd-flow
/plugin install sdd-flow@sdd-flow
```

重启 Claude Code 后，`/sdd` 命令和五个子 Agent 自动注册。

### 验证

```bash
# 在 Claude Code 中执行
/sdd --help
# 应显示可用命令
```

### 关键约定

sdd-flow 要求项目根目录存在 `AGENTS.md` 文件（项目规范文档，sdd-flow 只读不写）。没有此文件时 sdd-flow 会报错 `FAIL — AGENTS.md missing`。

## 3. 可选工具

### LiorCohen/sdd

轻量级 SDD CLI，npm 全局安装：

```bash
npm install -g sdd
sdd --help
```

适合不想引入 Spec Kit 完整结构、只需轻量规范管理的小型项目。

### archiet-microcodegen

L4 级别的规范编译器，从规范直接生成完整应用（不需要 LLM）：

```bash
# 参考项目，无需安装
git clone https://github.com/archiet-ai/microcodegen.git
```

## 5. 环境验证脚本

创建以下验证脚本确认环境就绪：

```bash
#!/bin/bash
# check-sdd-env.sh

echo "=== SDD 环境检查 ==="

# GitHub Spec Kit
if command -v specify &>/dev/null || pipx list 2>/dev/null | grep -q specify; then
    echo "✓ GitHub Spec Kit 已安装"
else
    echo "✗ GitHub Spec Kit 未安装（可通过 uvx --from 直接使用）"
fi

# Git
if command -v git &>/dev/null; then
    echo "✓ Git $(git --version | cut -d' ' -f3)"
else
    echo "✗ Git 未安装"
fi

# gh CLI
if command -v gh &>/dev/null; then
    echo "✓ GitHub CLI $(gh --version | head -1 | grep -oP '[\d.]+')"
else
    echo "✗ GitHub CLI 未安装"
fi

# Claude Code（如果使用 sdd-flow）
if command -v claude &>/dev/null; then
    echo "✓ Claude Code 已安装"
else
    echo "ℹ Claude Code 未安装（仅使用 Spec Kit 可跳过）"
fi

echo "=== 检查完成 ==="
```

```bash
chmod +x check-sdd-env.sh
./check-sdd-env.sh
```
