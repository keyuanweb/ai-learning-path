# 环境搭建

## 安装 Claude Code

### 方式一：npm 全局安装（推荐）

```bash
npm install -g @anthropic-ai/claude-code
```

### 方式二：一键安装脚本

```bash
# macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash
```

### 方式三：macOS Homebrew

```bash
brew install claude-code
```

安装完成后验证：

```bash
claude --version
```

## 认证

首次运行需要认证：

```bash
claude login
```

浏览器会自动打开，登录你的 Anthropic 账号完成授权。

企业用户可以通过 API Key 认证：

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

或者通过 AWS Bedrock / Google Vertex AI 接入：

```bash
# AWS Bedrock
claude --bedrock

# Google Vertex AI
claude --vertex
```

## 基本配置

### settings.json

全局配置文件位于 `~/.claude/settings.json`，项目级配置文件位于 `.claude/settings.json`。

```json
{
  "model": "sonnet",
  "permissionMode": "default",
  "theme": "dark"
}
```

### 模型选择

| 命令 | 说明 |
|------|------|
| `/model` | 交互式切换模型 |
| `claude --model opus` | 启动时指定模型 |
| `claude --model sonnet` | 使用 Sonnet（默认） |

可用模型：`opus`（最强推理）、`sonnet`（平衡速度与质量）、`haiku`（最快最经济）

### 权限模式

| 模式 | 说明 |
|------|------|
| `default` | 标准权限提示 |
| `plan` | 只读模式，不执行写操作 |
| `accept-edits` | 自动接受编辑 |

```bash
claude --permission-mode plan
```

## 项目初始化

进入你的项目目录，运行：

```bash
cd your-project
claude
```

首次使用时建议运行 `/init` 自动生成 `CLAUDE.md` 项目记忆文件。

```mermaid
flowchart LR
    A["claude login<br/>认证"] --> B["cd project"]
    B --> C["/init<br/>初始化 CLAUDE.md"]
    C --> D["开始对话式开发"]
```

## 常用启动选项

```bash
# 非交互式单次查询
claude -p "解释这个项目的架构" --output-format json

# 指定工作目录
claude --cwd /path/to/project

# 使用 git worktree 隔离工作
claude --worktree

# 调试模式
claude --debug

# 持续模式（自动重试出错任务）
claude --resume
```

## 版本更新

```bash
# npm 安装方式
npm update -g @anthropic-ai/claude-code

# 检查版本
claude --version
```

## 验证安装

创建一个简单测试：

```bash
mkdir test-claude && cd test-claude
echo "# Test Project" > README.md
claude -p "读取 README.md 并总结内容" --output-format text
```

如果输出包含 "Test Project" 相关内容，说明安装成功。
