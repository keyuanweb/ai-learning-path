# 环境搭建

## Python 版本

要求 Python 3.10+，推荐 Python 3.12。

```bash
python --version  # 确认版本
```

推荐使用虚拟环境：

```bash
python -m venv langgraph-env
source langgraph-env/bin/activate  # Linux/Mac
# langgraph-env\Scripts\activate   # Windows
```

## 安装核心包

```bash
pip install langchain langgraph langchain-openai langchain-community
```

### 可选依赖

```bash
# 向量数据库
pip install chromadb

# LLM 观测平台
pip install langsmith

# 生产平台（LangGraph Platform 需要）
pip install langgraph-cli

# 多 Agent 高级库
pip install langgraph-supervisor

# Web 搜索工具
pip install tavily-python
```

## API Key 配置

### OpenAI

```bash
export OPENAI_API_KEY="sk-..."
```

或在代码中配置：

```python
import os
os.environ["OPENAI_API_KEY"] = "sk-..."
```

### LangSmith（强烈推荐，用于调试和观测）

```bash
export LANGCHAIN_TRACING_V2="true"
export LANGCHAIN_API_KEY="ls_..."
export LANGCHAIN_PROJECT="langgraph-learning"
```

### Tavily（Web 搜索）

```bash
export TAVILY_API_KEY="tvly-..."
```
