# 环境搭建

## 前置依赖

### Node.js 18+

OpenClaw 基于 Node.js 构建，需要 18.x 或更高版本：

```bash
# 检查版本
node --version  # 应 >= 18.0.0
npm --version

# 如未安装，推荐使用 nvm 管理版本
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
nvm install 18
nvm use 18
```

### Docker（可选，沙箱子Agent 需要）

```bash
docker --version
```

## 安装 OpenClaw

### 方式一：npm 全局安装（推荐）

```bash
npm install -g openclaw
```

安装完成后验证：

```bash
openclaw --version
```

### 方式二：从源码安装

```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
npm install
npm run build
npm link
```

## 初始化配置

```bash
# 交互式初始化向导
openclaw setup
```

初始化过程会引导你完成：
1. **LLM Provider 配置** — 选择模型提供商（Claude/GPT/Gemini/DeepSeek/Ollama/OpenRouter）
2. **API Key 配置** — 设置对应提供商的 API Key
3. **通道配置** — 勾选要启用的消息平台（Telegram/Discord/Slack 等）
4. **Workspace 初始化** — 创建 Agent 工作目录

## 配置文件结构

OpenClaw 使用 YAML/JSON 混合配置，主要配置文件：

```
~/.openclaw/
├── config.yaml          # 主配置文件（Gateway、Agent、Skills、Memory）
├── identities/          # Agent 身份定义
│   └── default.yaml
├── workspaces/          # Agent 工作空间
│   └── default/
│       ├── AGENTS.md    # 项目级 Agent 指令
│       ├── IDENTITY.md  # Agent 身份描述
│       ├── SOUL.md      # Agent 个性与价值观
│       ├── USER.md      # 用户画像与偏好
│       ├── MEMORY.md    # 长时记忆
│       └── TOOLS.md     # 可用工具清单
└── skills/              # 本地技能目录
```

### 最小 config.yaml

```yaml
gateway:
  port: 18789
  bind: 127.0.0.1

agent:
  provider: anthropic
  model: claude-sonnet-4-6
  workspace: default

channels:
  telegram:
    enabled: false
    token: ""
```

### 多 Provider 配置示例

```yaml
agent:
  default_provider: anthropic
  providers:
    anthropic:
      api_key: ${ANTHROPIC_API_KEY}
      model: claude-sonnet-4-6
    openai:
      api_key: ${OPENAI_API_KEY}
      model: gpt-5
    deepseek:
      api_key: ${DEEPSEEK_API_KEY}
      model: deepseek-v3
```

## 启动 Agent

### 本地 CLI 模式

```bash
# 进入工作空间
cd ~/.openclaw/workspaces/default

# 启动交互式会话
openclaw chat
```

### Gateway 模式（多通道接入）

```bash
# 启动 Gateway + 所有启用的通道
openclaw gateway start

# 查看 Gateway 状态
openclaw gateway status

# Web Dashboard
openclaw dashboard
```

Dashboard 默认运行在 `http://127.0.0.1:18789/`。

### Docker 沙箱模式

```bash
# 在 Docker 沙箱中启动 Agent（隔离执行）
openclaw sandbox start
```

## 验证安装

创建测试工作空间并运行第一个对话：

```bash
# 创建测试工作空间
openclaw workspace create test
cd ~/.openclaw/workspaces/test

# 编辑 AGENTS.md 定义简单任务
echo "# Test Agent" > AGENTS.md

# 运行单次交互测试
openclaw chat -p "Hello, what tools do you have access to?"

# 如果输出工具列表，说明安装成功
```

## 常用命令速查

| 命令 | 说明 |
|------|------|
| `openclaw setup` | 交互式初始化 |
| `openclaw chat` | 启动 CLI 对话 |
| `openclaw gateway start` | 启动多通道网关 |
| `openclaw dashboard` | 打开 Web 控制台 |
| `openclaw workspace list` | 列出工作空间 |
| `openclaw workspace create <name>` | 创建工作空间 |
| `openclaw skill install <name>` | 安装 ClawHub 技能 |
| `openclaw sandbox start` | 启动 Docker 沙箱 |
| `openclaw --debug` | 调试模式 |

## 实践练习

1. 安装 OpenClaw 并完成 `openclaw setup` 初始化
2. 配置至少一个 LLM Provider（推荐先用 OpenRouter 体验多模型）
3. 浏览自动生成的 Workspace 文件（AGENTS.md / IDENTITY.md 等）
4. 运行第一个对话，观察 Agent 的 ReAct 循环过程
5. （可选）配置 Telegram Bot Token，通过手机与 Agent 对话
