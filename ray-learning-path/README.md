# Ray 分布式计算框架 — 学习路径

Ray 是一个开源的统一分布式计算框架，为 ML/AI 工作负载而生。从单机到上千节点的集群，Ray 提供 Task（无状态函数）、Actor（有状态对象）、Object（分布式共享数据）三大原语，以及 Data/Train/Tune/Serve/RLlib 五大 AI 库，覆盖数据处理、分布式训练、超参数优化、模型服务和强化学习的全流程。

本学习路径从零开始，先理解 Ray Core 的核心抽象和底层机制，再逐步深入到 AI 库和集群生产部署。

| 阶段 | 内容 | 预计学时 |
|------|------|----------|
| 00-入口 | Ray 定位与架构全景、环境搭建、第一个分布式程序 | 2h |
| 01-核心抽象 | Task 远程任务、Actor 参与者、Object 远程对象、三大抽象配合 | 6h |
| 02-对象管理机制 | Plasma 对象存储原理、零拷贝与内存层级、引用计数与 GC | 5h |
| 03-调度系统 | 两级调度架构、资源抽象与管理、放置组策略、调度策略与亲和性 | 6h |
| 04-容错与一致性 | 血统重建容错、Actor 故障恢复、GCS 全局控制存储 | 5h |
| 05-AI 库总览 | 生态全景、Ray Data 数据处理、Ray Train 分布式训练入门 | 4h |
| 06-训练与调优 | Ray Train 深度、Ray Tune 超参数优化、PyTorch/TF 集成、大规模训练最佳实践 | 8h |
| 07-模型服务 | Ray Serve 核心概念、自动扩缩容原理、多模型编排与流水线、高级部署模式 | 6h |
| 08-集群与生产 | 集群架构详解、KubeRay 云原生部署、监控与可观测性、生产性能调优 | 6h |
| 09-高级专题 | RLlib 强化学习、Ray 与 MLOps、自定义扩展、案例研究（OpenAI/Uber/Shopify） | 6h |
| 10-LLM-Wiki | LLM Wiki 知识库构建方法论（Karpathy）— 编译器模式、三层架构、防幻觉策略 | 3h |

**总计约 57 学时**

## 学习建议

1. **必学基础**（00-04）：无论你做什么方向，Ray Core（Task/Actor/Object + 调度 + 对象管理 + 容错）是理解一切的基础
2. **按需选择**（05-09）：做训练的深入 05-06，做推理的深入 07，做平台的深入 08，做研究的深入 09
3. **动手优先**：每学一个概念立刻写代码验证，Ray 的本地模式让你在本机就能体验分布式
4. **善用 Dashboard**：`http://127.0.0.1:8265` 是理解分布式行为的窗口
