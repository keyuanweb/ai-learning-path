从 FP16 模型到量化推理服务的完整流程。

## 1. AWQ 量化 + vLLM 部署 (GPU)

### 完整流程

```bash
# Step 1: 安装
pip install autoawq vllm

# Step 2: 量化模型
# autoawq 自动处理校准 → 量化 → 打包
```

```python
from awq import AutoAWQForCausalLM
from transformers import AutoTokenizer

model_path = "meta-llama/Llama-3-8B"
quant_path = "Llama-3-8B-AWQ"

# 加载模型
model = AutoAWQForCausalLM.from_pretrained(model_path)
tokenizer = AutoTokenizer.from_pretrained(model_path)

# 量化配置
quant_config = {
    "zero_point": True,           # 使用零点（非对称量化）
    "q_group_size": 128,          # 每 128 个权重共享一个 scale
    "w_bit": 4,                   # INT4
    "version": "GEMM",            # 使用 GEMM kernel（最快）
}

# 量化
model.quantize(tokenizer, quant_config=quant_config)

# 保存
model.save_quantized(quant_path)
tokenizer.save_pretrained(quant_path)
```

```bash
# Step 3: vLLM 部署量化模型
vllm serve Llama-3-8B-AWQ --quantization awq --dtype bfloat16 --max-model-len 4096
```

### 效果验证

```python
# 对比量化前后的输出质量
original = generate("original_model", prompt)
```

## 2. GGUF 量化 + llama.cpp (CPU/边缘)

### 完整流程

```bash
# Step 1: 转换 HF 模型为 GGUF
pip install llama-cpp-python

python convert_hf_to_gguf.py Llama-3-8B --outtype f16
# 输出: Llama-3-8B-F16.gguf (~14 GB)

# Step 2: 量化 (选择量化级别)
llama-quantize Llama-3-8B-F16.gguf Llama-3-8B-Q4_K_M.gguf Q4_K_M
```

### 量化级别选择

| 格式 | 大小 (7B) | 质量 | CPU 速度 | 推荐 |
|------|----------|------|---------|------|
| Q2_K | 2.8 GB | 显著下降 | 最快 | 不推荐 |
| Q3_K_M | 3.6 GB | 可接受 | 快 | 内存 < 6GB |
| **Q4_K_M** | **4.4 GB** | **很好** | **快** | **推荐** |
| Q5_K_M | 5.3 GB | 更好 | 中等 | 内存充裕时 |
| Q6_K | 6.6 GB | 接近原版 | 较慢 | 要求质量时 |
| Q8_0 | 7.7 GB | 几乎无损 | 更慢 | 内存 > 8GB |
| F16 | 14 GB | 无损 | 慢 | 基线 |

**Q4_K_M 是性价比之颠。**

### 推理

```python
from llama_cpp import Llama

llm = Llama(
    model_path="Llama-3-8B-Q4_K_M.gguf",
    n_ctx=4096,            # 上下文长度
    n_threads=8,           # CPU 线程数
    n_gpu_layers=-1,       # -1 = 所有层放 GPU (如果有 Metal/CUDA)
)

output = llm("法国的首都是哪里？", max_tokens=128)
print(output["choices"][0]["text"])
```

## 3. 端到端成本收益分析

### 7B 模型部署方案对比

| 方案 | 显存/内存 | 吞吐 | 月成本 | 质量 |
|------|---------|------|--------|------|
| BF16 + A100 | 16 GB | 4000 t/s | ~$1800 | 100% |
| AWQ INT4 + A100 | 6 GB | 8000 t/s | ~$1800 | 98-99% |
| AWQ INT4 + RTX 4090 | 6 GB | 4000 t/s | ~$360 | 98-99% |
| GGUF Q4 + M2 Ultra | 6 GB | 300 t/s | ~$0 (自有) | 97-98% |
| GGUF Q4 + CPU (i9) | 6 GB | 80 t/s | ~$0 (自有) | 97-98% |

**结论**：AWQ INT4 + RTX 4090 是云部署的性价比最优解。GGUF Q4 + Mac 是个人使用的最优解。
