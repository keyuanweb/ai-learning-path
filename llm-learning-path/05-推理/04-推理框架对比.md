# 推理框架对比

选择合适的推理框架是部署环节最重要的决策。不同框架的优化重点不同。

---

## 1. 框架全景

```
                  追求高吞吐
                  /        \
          vLLM / TGI      TensorRT-LLM
         (开源通用)       (极致优化, 需要编译)
                |
           SGLang (结构化生成, 最新)
                |
           llama.cpp (CPU/边缘)
                |
           Ollama (一键本地部署)
```

---

## 2. 各框架详解

### vLLM

**核心优化**：PagedAttention（上一章已详述）。

**优势**：
- 开箱即用，无需编译
- OpenAI 兼容 API
- 社区最活跃
- Continuous batching + prefix caching

**劣势**：
- 对非 NVIDIA GPU 支持有限
- 部分小众模型需要等待适配

### TGI (Text Generation Inference by HuggingFace)

**核心优化**：类似 vLLM 的 PagedAttention + 更多 HuggingFace 原生特性。

**优势**：
- HuggingFace 官方维护
- 与 HF Hub 模型无缝集成
- 支持水印 (watermark) 和语法约束生成

**劣势**：
- 吞吐量略低于 vLLM
- 社区相对较小

### TensorRT-LLM (NVIDIA)

**核心优化**：图编译优化 + Kernel Fusion（融合多个小算子为一个大 kernel）+ 量化。

**优势**：
- **极致性能**：比 vLLM 再快 30-80%
- 最好的 FP8/INT8/INT4 量化支持
- NVIDIA 官方优化

**劣势**：
- 需要**编译模型**（构建 TensorRT engine，可能需要几小时）
- 对新模型架构需要等待支持
- 使用门槛最高

**适用场景**：追求极限吞吐的生产环境，模型已经稳定不需要频繁更换。

### SGLang

**核心优化**：RadixAttention（前缀树共享）+ 结构化生成。

**优势**：
- 对复杂 prompt 结构（多轮、多分支）的 KV Cache 共享最优
- 结构化 JSON/代码生成效率高
- 2025 年增长最快的推理框架

### llama.cpp

**核心优化**：CPU 推理 + 激进量化（GGUF 格式）+ mmap 加载。

**优势**：
- **不需要 GPU**！纯 CPU 推理
- 支持 1.5-bit 到 8-bit 的多种量化
- 在 Apple Silicon (M1/M2/M3) 上利用 Metal/MLX 加速

**适用场景**：本地运行、边缘设备、隐私敏感场景。

### Ollama

封装 llama.cpp 的桌面应用，一键启动本地 LLM 服务：
```bash
ollama run llama3
```

## 3. 框架选择指南

| 场景 | 推荐 | 原因 |
|------|------|------|
| **在线 API 服务（通用）** | vLLM | 平衡性能与易用性 |
| **在线 API 服务（HF 深度用户）** | TGI | HF 生态原生 |
| **生产极致优化（NVIDIA GPU）** | TensorRT-LLM | 最高吞吐 |
| **复杂 prompt/结构化输出** | SGLang | RadixAttention 优势 |
| **本地/边缘 CPU 推理** | llama.cpp | 无 GPU 需求 |
| **个人桌面快速体验** | Ollama | 一键启动 |
| **单卡部署大模型** | vLLM + AWQ 量化 | 量化 + 高吞吐 |

---

## 4. 性能基准参考

以 LLaMA-3-8B (A100 80G, BF16, 1024 input / 256 output) 为基准：

| 框架 | 吞吐 (tokens/s) | 延迟 (ms/token) | 显存 |
|------|----------------|-----------------|------|
| vLLM | ~4000 | ~25 | 好 |
| TGI | ~3500 | ~28 | 好 |
| TensorRT-LLM | ~6000 | ~16 | 最优 |
| SGLang | ~4200 | ~24 | 好 |
| llama.cpp (M2 Ultra) | ~150 | ~650 | 无 GPU 需求 |
