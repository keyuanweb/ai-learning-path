# 从零预训练实战工业级

在 [03-训练/08-从零预训练一个小模型.md](../03-训练/08-从零预训练一个小模型.md) 中我们用 TinyStories 训练了一个玩具模型。这一章讲工业级的预训练实践——以 SmolLM3 和 OLMo 为参考。

---

## 1. 工业级预训练与 Toy 预训练的区别

| 维度 | Toy (TinyStories) | 工业级 |
|------|-------------------|--------|
| 模型大小 | <100M | 1B-7B+ |
| 数据量 | ~1GB | 1-10TB+ |
| 训练时长 | 几小时 | 几天到几周 |
| GPU | 1 张 | 32-512 张 |
| 数据配比 | 单一来源 | 多来源精心配比 |
| 消融实验 | 无 | 必做（验证每个设计选择） |

---

## 2. 数据配比：预训练最重要的决策

### 问题

你不会把整个互联网不加筛选地喂给模型。不同来源的数据质量和价值不同，需要精心配比。

### SmolLM3 的数据配比（参考）

| 数据源 | 占比 | 作用 |
|--------|------|------|
| Web (CommonCrawl 精选) | 50% | 基础语言能力 |
| 代码 (GitHub 开源) | 25% | 代码能力 |
| 数学/科学 (arXiv, textbooks) | 10% | 推理能力 |
| 多语言 (维基、新闻) | 10% | 多语言覆盖 |
| 指令/对话 | 5% | 对齐基础 |

### 配比的核心原则

- **代码占比高 → 推理能力提升**（代码是结构化的逻辑推理数据）
- **多语言混合 → 跨语言迁移**（英语数据对中文有帮助，反之亦然）
- **高质量数据 > 海量低质量数据**（在固定训练预算下，少而精比多而杂好）

## 3. 消融实验：验证每一个选择

在工业级预训练中，你不能"全部改完再看效果"。每个设计选择都要通过消融实验验证：

```python
# 实验矩阵
experiments = [
    {"name": "baseline", "data_ratio": [50,25,10,10,5], "lr": 3e-4, "warmup": 2000},
    {"name": "more_code", "data_ratio": [40,35,10,10,5], "lr": 3e-4, "warmup": 2000},
    {"name": "higher_lr", "data_ratio": [50,25,10,10,5], "lr": 5e-4, "warmup": 2000},
    # ...
]

# 在 1B 模型上跑 10B tokens → 选最佳配置 → 扩展到 7B 全量训练
```

**关键节省**：在 100M 参数上做消融，把最佳配置用于 7B。不要在 7B 上做消融——太贵。

## 4. 长周期训练的关键监控

### Loss Spike 处理

训练中 loss 突然飙升（spike）是常见故障。原因可能是坏数据、梯度爆炸、优化器状态损坏。

```python
# 训练循环中的监控
if current_loss > running_average * 3:  # loss 突然为平均的 3 倍
    # 不回退到上一个 checkpoint！先跳过这个 batch
    log_warning(f"Loss spike detected: {current_loss}")
    continue  # 不更新参数

# 如果连续 3 个 batch 都有问题 → 回退 checkpoint
if spike_count >= 3:
    restore_from_checkpoint()
```

### 学习率调度：WSD (Warmup-Stable-Decay)

```python
def wsd_scheduler(step, warmup_steps, stable_steps, total_steps, max_lr, min_lr):
    if step < warmup_steps:
        return max_lr * step / warmup_steps           # 线性预热
    elif step < warmup_steps + stable_steps:
        return max_lr                                  # 稳定期（多数训练在此）
    else:
        # 余弦衰减
        progress = (step - warmup_steps - stable_steps) / (total_steps - warmup_steps - stable_steps)
        return min_lr + 0.5 * (max_lr - min_lr) * (1 + math.cos(math.pi * progress))
```

WSD 的核心思想：让模型在最大学习率下"充分学习"，最后快速衰减到最小值收敛。

## 5. 工业级预训练的检查清单

- [ ] 数据去重（MinHash 或 Exact Dedup）——重复数据浪费算力
- [ ] 数据质量过滤（困惑度过滤、长度过滤、语言检测）
- [ ] 配比消融实验在 1/10 规模上完成
- [ ] 训练脚本能自动恢复（从 checkpoint 继续，不重跑）
- [ ] Loss 监控 + Spike 自动处理
- [ ] 定期在 Benchmark 上评估（每 10B tokens 一测）
- [ ] Gradient Clipping 已启用（max_norm=1.0）
- [ ] 模型 checkpoint 自动上传（别只存在训练机器上！）
