# 持续预训练

持续预训练 (Continual Pre-training) = 在一个已经预训练好的模型上，用新领域数据继续训练。这是将通用模型变成领域专用模型的最有效路径之一。

---

## 1. 解决的问题

### 场景

你有一个 Qwen2.5-7B 的通用模型，但你需要它在医疗领域表现优秀。通用模型知道基础医学知识，但不精通具体病症、药物名称、诊断逻辑。

### 为什么不是直接微调

SFT 教模型"用什么格式回答"，不能从根本上改变模型的知识结构。持续预训练让新知识融入模型的参数，而不仅仅是"表面行为"。

---

## 2. 核心挑战：灾难性遗忘

### 什么是灾难性遗忘

在学习新知识时，模型会"忘记"之前学过的通用能力。

```
预训练后:   语言能力 ████████ 医疗知识 ███
持续训练后: 语言能力 ████     医疗知识 ████████  ← 通用能力退了！
```

### 为什么会发生

梯度下降只朝着"让当前 batch 的 loss 变小"的方向更新参数。当新数据只有医疗文本时，模型会过度适应医疗分布，改变那些也负责通用能力的参数。

---

## 3. 缓解策略

### 策略 1：数据混合

在领域数据中混入一定比例的通用数据（来自原始预训练语料）。

```python
# 不纯用医疗数据，混合 10-20% 的通用数据
train_data = ConcatDataset([
    DomainDataset("medical_texts"),     # 80%
    GeneralDataset("web_crawl_sample"),  # 20%  ← 保持通用能力
])
```

### 策略 2：学习率衰减

用远低于原始预训练的学习率（10× 到 100× 小）。

```python
# 原始预训练 lr = 3e-4
# 持续预训练 lr = 3e-5 或 1e-5  ← 微幅更新，不剧烈扰动参数
```

### 策略 3：弹性权重巩固 (EWC)

对"对通用能力重要的参数"施加更大的更新阻力。

```python
# EWC 在标准 loss 上加一个惩罚项
loss = domain_loss + lambda_ewc * sum(
    fisher_info[i] * (param[i] - original_param[i]) ** 2
    for i in range(num_params)
)
# fisher_info[i] 大 → 参数 i 对原任务很重要 → 不能大改
```

### 策略 4：定期评估通用能力

```python
# 每 1000 步在通用 benchmark 上测一次
if step % 1000 == 0:
    general_score = evaluate(model, tasks=["mmlu", "hellaswag"])
    if general_score < best_general_score * 0.95:  # 通用能力下降 5%
        log_warning("灾难性遗忘征兆，调整数据配比或降低学习率")
```

---

## 4. 数据量要求

持续预训练至少需要多少领域数据？

| 领域数据量 | 效果 |
|-----------|------|
| <100M tokens | 效果不明显，不如直接 SFT |
| 1B-10B tokens | 效果初显，知识开始融入 |
| 50B-100B tokens | 显著效果，知识深度注入 |
| 500B+ tokens | 接近全量预训练的效果 |

**经验法则**：持续预训练需要 10B+ tokens 才能对 7B 模型产生显著效果。数据不够就考虑 RAG 或 SFT。

---

## 5. 持续预训练 vs SFT vs RAG

| 维度 | 持续预训练 | SFT | RAG |
|------|-----------|-----|-----|
| **知识融入深度** | 深（参数级） | 浅（行为级） | 无（外部检索） |
| **数据量需求** | 大（10B+ tokens） | 小（1K-10K 条） | 中等（文档数） |
| **遗忘风险** | 中 | 低 | 无 |
| **成本** | 高（GPU 天级别） | 低（GPU 小时） | 中（存储+检索） |
| **适用场景** | 深度领域知识 | 格式对齐 | 知识实时更新 |
