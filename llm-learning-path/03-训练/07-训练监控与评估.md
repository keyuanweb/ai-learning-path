# 训练监控与评估

大模型训练通常持续数周到数月。没有完善的监控，就像开飞机没有仪表盘——等发现坠毁时已经晚了。

---

## 1. 核心监控指标

### 训练期间必须追踪的指标

| 指标 | 含义 | 异常信号 |
|------|------|---------|
| **Training Loss** | 模型对训练数据的拟合程度 | 不降、骤升 (spike) |
| **Gradient Norm** | 梯度的 L2 范数 | 突然变大几十倍 → 即将发散 |
| **Learning Rate** | 当前调度器设置的学习率 | 确认 warmup/decay 正常执行 |
| **Perplexity (验证集)** | 模型的泛化能力 | 训练 PPL 在降但验证 PPL 在涨 → 过拟合 |
| **Token 吞吐量** | tokens/second/GPU | 确认无通信瓶颈、无 GPU 空闲 |
| **GPU 利用率** | % 计算单元在工作 | <80% → 数据加载或通信是瓶颈 |
| **GPU 显存使用** | 已用/总量 | 接近 100% → 可能要 OOM |

## 2. 监控工具

### Weights & Biases (Wandb)

大模型社区的事实标准。自动记录所有指标，提供实时仪表盘、历史对比、异常告警。

```python
import wandb
wandb.init(project="llm-pretraining", config={
    "model": "llama-7b",
    "batch_size": 256,
    "lr": 3e-4,
})

for step, batch in enumerate(dataloader):
    loss = model(batch)
    wandb.log({
        "train/loss": loss.item(),
        "train/grad_norm": grad_norm,
        "train/lr": scheduler.get_last_lr()[0],
        "train/tokens_per_sec": tokens_per_sec,
        "system/gpu_utilization": gpu_util,
    }, step=step)
```

## 3. Benchmark 评估

### 中间评估

训练期间定期（如每 5000 步）在标准 Benchmark 上评估模型：

| Benchmark | 测什么 | 任务数 |
|-----------|--------|--------|
| **MMLU** | 多领域知识（数学、历史、法律、医学等 ~57 个学科） | 57 |
| **HellaSwag** | 常识推理（完成句子，选择题） | 10K |
| **ARC** | 科学推理（高中科学题） | 7.5K |
| **HumanEval** | 代码生成（写 Python 函数） | 164 |
| **GSM8K** | 小学数学应用题 | 1320 |
| **BBH** | 复杂多步推理 | 23 |

## 4. 为什么验证 PPL 和 Benchmark 表现可能不一致

### 问题

训练 PPL 在下降，但 MMLU 分数在下降。这说明模型在"记忆训练数据的表面模式"而非"学习可迁移的知识"。

### 原因

- **数据泄露**：验证集中混入训练数据 → PPL 虚低
- **Domain mismatch**：训练数据（代码为主）与 Benchmark（常识推理）分布不一致
- **PPL 测的是"流利度"而非"正确性"**：流畅的废话 PPL 也低

### 应对

- 定期跑下游 Benchmark 而非只看 PPL
- 使用独立的/未出现在训练集中的评估数据
- PPL 作为"预警指标"，Benchmark 作为"决策指标"

## 5. 训练日志的最佳实践

```python
# 所有关键信息集中记录
log = {
    "step": global_step,
    "epoch": epoch,
    "loss": float(loss),
    "ppl": math.exp(float(loss)),
    "grad_norm": float(grad_norm),
    "lr": scheduler.get_last_lr()[0],
    "tokens_processed": global_step * batch_size * seq_len,
    "throughput": tokens_per_second,
    "gpu_mem_gb": torch.cuda.max_memory_allocated() / 1e9,
    "wall_time_hours": elapsed.total_seconds() / 3600,
}
```

### 训练健康检查清单

```
每 100 步:  确认 loss 在下降趋势中
每 1000 步: 确认 grad_norm 无异常增大
每 5000 步: 保存 checkpoint + 跑验证集 PPL
每 10000 步: 跑 MMLU 等 Benchmark 子集
发现 spike:  立即停止训练，回滚 checkpoint，检查数据
```
