# 从零预训练一个小模型

> 最好的学习方式是亲手做一个。本章用 TinyStories 数据集从零预训练一个 ~30M 参数的小型语言模型。

---

## 1. 这个项目的目的

### 你将在实战中理解

- **数据流**：原始文本 → tokenize → batching → 训练
- **训练循环**：forward → loss → backward → gradient clip → optimizer step
- **训练稳定性**：warmup、学习率衰减、梯度裁剪的实际效果
- **生成评估**：观测模型从"乱码"到"连贯故事"的演变过程

**不需要多 GPU，一张 8GB 以上的消费级显卡即可完成。**

---

## 2. 数据集：TinyStories

TinyStories 是用 GPT-3.5/4 生成的英文儿童故事数据集（约 2M 条），专门设计用于小模型的预训练研究。

**为什么选择它**：
- 词汇和句式简单，小模型也能学会
- 数据"干净"（AI 生成），无需复杂的数据工程
- 有标准的验证集和评估工具
- 30M 参数模型训练 1-2 小时就能看到合理的故事生成

### 训练 Tokenizer

```python
from tokenizers import Tokenizer, models, trainers, pre_tokenizers

# 在 TinyStories 上训练 BPE tokenizer
tokenizer = Tokenizer(models.BPE())
tokenizer.pre_tokenizer = pre_tokenizers.ByteLevel(add_prefix_space=False)
trainer = trainers.BpeTrainer(vocab_size=8192, special_tokens=["<|endoftext|>"])

# 读取数据集训练 tokenizer
def batch_iterator():
    for i in range(0, len(dataset), 1000):
        yield dataset[i:i+1000]["text"]

tokenizer.train_from_iterator(batch_iterator(), trainer=trainer)
tokenizer.save("tinystories_tokenizer.json")
```

### 训练循环

```python
optimizer = torch.optim.AdamW(model.parameters(), lr=5e-4,
                               betas=(0.9, 0.95), weight_decay=0.1)

for step in range(10000):
    # Warmup + Cosine Decay
    if step < 500:
        lr = 5e-4 * step / 500
    else:
        progress = (step - 500) / 9500
        lr = 5e-5 + 0.5 * (5e-4 - 5e-5) * (1 + math.cos(math.pi * progress))
    for pg in optimizer.param_groups:
        pg['lr'] = lr

    # 梯度累积
    total_loss = 0
    for micro_step in range(4):
        with torch.autocast(device_type='cuda', dtype=torch.bfloat16):
            _, loss = model(x_micro, y_micro)
            loss = loss / 4  # 梯度累积缩放
        loss.backward()
        total_loss += loss.item()

    # 梯度裁剪 + 更新
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()
    optimizer.zero_grad()

    if step % 100 == 0:
        print(f"Step {step}: loss={total_loss:.3f}, ppl={math.exp(total_loss):.1f}, lr={lr:.2e}")
```

## 4. 预期结果

### 训练进程

| 步骤 | Loss | PPL | 生成表现 |
|------|------|-----|---------|
| 0 | ~8.0 | ~3000 | 完全随机乱码 |
| 500 (warmup结束) | ~3.5 | ~33 | 偶尔有完整单词 |
| 2000 | ~2.3 | ~10 | 有基本语法结构 |
| 5000 | ~1.8 | ~6 | 连贯的简单故事 |
| 10000 | ~1.5 | ~4.5 | 相对通顺的短文 |

## 5. 关键调参经验

| 问题 | 表现 | 解决方案 |
|------|------|---------|
| **Loss 不降** | 前 1000 步 loss 卡住 | 增大 lr，检查 tokenizer 是否正确 |
| **Loss 震荡** | loss 上上下下，不收敛 | 减小 lr，增大 batch size |
| **Loss Spike** | 到某一步突然 loss 爆炸 | 降低 lr，检查梯度裁剪是否生效 |
| **生成大量重复** | "the cat and the cat and the cat" | 正常现象，更多训练后会改善 |
| **过拟合** | val PPL 在涨但 train PPL 在降 | 增大 dropout，减少训练步数 |

### 最重要的教训

> 数据质量 > 模型大小 > 训练技巧

这个 30M 模型的 TinyStories 生成效果，可能比用脏数据训练的 100M 模型更好。数据决定上限，模型和技巧只是逼近这个上限。
