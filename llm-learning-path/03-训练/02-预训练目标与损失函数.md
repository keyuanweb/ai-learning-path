# 预训练目标与损失函数

大模型训练的一切都归结为一个简洁的公式：**最小化下一个 token 预测的交叉熵**。但在这个简洁公式背后，有多个设计决策需要考虑。

---

## 1. 核心训练目标：Next Token Prediction

### 解决了什么

> 如何从海量无标注文本中学习到通用的语言理解和生成能力？

答案是一个不需要人工标注的自监督目标：对于任意文本序列，用前文预测下一个 token。

$$\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log P(w_i \mid w_1, ..., w_{i-1}; \theta)$$

### 为什么这个目标足够

这个目标强迫模型学会：
- **语法**：预测动词形式需要知道主语是单数还是复数
- **语义**：预测连贯的后续需要理解前面的含义
- **事实知识**：预测"中国的首都是[?]"需要知道事实
- **逻辑推理**：预测推理题的结论需要多步推导
- **代码执行**：预测下一行代码需要理解上一行做了什么

**"猜下一个词"这个简单的任务，囊括了所有语言智能。**

## 2. 交叉熵损失的详细计算

### 实现

```python
# logits: [batch, seq_len, vocab_size] — 模型输出
# labels: [batch, seq_len]            — 每个位置的真实token ID

loss = F.cross_entropy(
    logits.view(-1, vocab_size),   # [batch*seq, vocab_size]
    labels.view(-1),               # [batch*seq]
    ignore_index=-100              # 忽略padding位置
)
```

### 为什么使用 Cross-Entropy 而不是 MSE

| | Cross-Entropy | MSE |
|---|---|---|
| **适用场景** | 分类（离散概率分布） | 回归（连续值） |
| **梯度特性** | 预测越错，梯度越大（好的学习信号） | 预测很错时梯度反而小 |
| **与 softmax 配合** | 梯度 = softmax - onehot（极简形式） | 复杂 |

Cross-Entropy + Softmax 的组合有一个优美的梯度性质：

$$\frac{\partial L}{\partial z_i} = \hat{y}_i - y_i$$

（对第 i 个 logit 的梯度 = 预测概率 - 真实概率）

当预测接近真实时（$\hat{y} \approx 1$），梯度趋近 0 → 不再更新（学到了）。当预测偏差大时（$\hat{y} \approx 0$），梯度大 → 快速修正。**学习信号与偏差成正比**，这是最理想的情况。

## 3. 预训练目标的变体

### CLM (Causal Language Modeling) — Decoder-Only

$$P(w_1, ..., w_n) = \prod_{i=1}^{n} P(w_i \mid w_{<i})$$

- 单向（从左到右），每个 token 只能看到之前的
- GPT、LLaMA 的标准目标
- **优点**：统一、自然，适合生成。**缺点**：每个 token 只能利用一半的上下文（前面）

### MLM (Masked Language Modeling) — Encoder-Only

$$P(w_{masked} \mid w_{unmasked})$$

- 随机 mask 15% 的 token，模型用双向上下文预测它们
- BERT 的标准目标
- **优点**：充分利用双向上下文。**缺点**：不能用于生成

### Prefix Language Modeling

前半部分双向（prefix），后半部分单向（生成）。GLM 使用。
- **优点**：兼顾理解与生成。**缺点**：实现更复杂

### Span Corruption — Encoder-Decoder

随机破坏输入文本中的若干区间，让模型还原。T5 使用。

## 4. 损失函数的工程细节

### 为什么要 ignore padding

padding token 的预测不应该计入损失——模型不应该学习"padding 后接 padding"这种无意义的模式。

### Label Smoothing

将真实标签从 one-hot 软化（如 `[0, 0, 1, 0]` → `[0.02, 0.02, 0.90, 0.06]`）：

$$\hat{y}_i = (1-\alpha) \cdot y_i + \alpha / K$$

- 解决的问题：模型过度自信（对正确 token 预测概率 > 0.999）
- 效果：轻微提升泛化能力，但对大模型效果不明显
- 现状：大模型预训练中不常用（数据量大了不需要）

### Z-loss（辅助损失）

对 logits 的平方和做额外的惩罚：

$$\mathcal{L}_z = \alpha \cdot \frac{1}{N} \sum \log^2(Z)$$

其中 $Z = \sum e^{z_i}$ 是 softmax 的分母（partition function）。

- 解决的问题：训练后期 logits 的值域无限增长（数值不稳定）
- 作用：约束 logits 在合理的数值范围内
- PaLM 等模型使用

---

## 5. 为什么预训练只用一个损失函数

对比其他领域（目标检测 = 分类损失 + 回归损失 + IoU 损失），大模型只用一个交叉熵损失的简洁性令人惊讶。这不是懒惰——这是精心设计的结果：

- **单一目标 = 没有多目标权重调优**
- **交叉熵是充分统计量**：只要损失降到足够低，所有隐含的能力（语法、知识、推理）都会随之提升
- **Scale 的简洁性**：越简单，越容易在工程上 scale
