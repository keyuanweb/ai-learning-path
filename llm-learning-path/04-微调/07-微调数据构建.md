# 微调数据构建

> 微调数据质量决定微调效果的上限。模型架构和训练技巧只能逼近这个上限。

---

## 1. Self-Instruct：用大模型生成微调数据

### 解决什么问题

人工标注微调数据太贵（一条高质量的 SFT 数据成本 $1-10）。Self-Instruct 用已有大模型**自动生成**指令-回答对。

### 流程

```
1. Seed Tasks (少量人工示例):
   "翻译成英文", "总结下文", "解释什么是X"

2. 用大模型生成更多指令:
   Prompt: "请根据以下示例，生成10个新的指令任务..."
   → 模型输出: 10个新指令

3. 对每个生成的指令，用大模型生成回答

4. 质量过滤:
   - 删除格式不正确的
   - 删除回答太短的
   - 删除与已有数据高度重复的
```

### Alpaca 数据集——Self-Instruct 的经典案例

用 GPT-3.5 生成了 52K 条指令-回答对，成本约 $500。用这个数据集微调的 LLaMA-7B (Alpaca) 在指令跟随能力上接近 GPT-3.5。

## 2. Evol-Instruct：逐步提升复杂度

### 解决 Self-Instruct 的问题

Self-Instruct 生成的数据**难度一致**——GPT 倾向于生成它擅长的中等难度指令。这导致微调后的模型在困难任务上表现差。

### Evol-Instruct 的做法

对每条指令**反复"升级"**，增加维度：
1. **增加约束**："写一首诗" → "写一首五言绝句，每句都要包含一种花的名字"
2. **深化推理**："解释这个概念" → "解释这个概念，并用它推导一个复杂场景的结果"
3. **增加步骤**："解决这个问题" → "分三步解决这个问题，每一步解释你的思路"
4. **增加输入**：从 abstract 指令变具体场景

每次升级后，再用模型生成对应的回答。经过几轮升级，数据集中的指令越来越复杂。

### WizardLM 的经验

用 Evol-Instruct + GPT-3.5 生成数据微调 LLaMA-7B，效果超过用 ChatGPT 原始生成的数据微调的模型。证明**指令复杂度**是关键变量。

## 3. 数据质量控制

### 过滤标准

| 过滤项 | 方法 | 阈值 |
|--------|------|------|
| 语言不匹配 | 语言检测 | 非目标语言的数据删除 |
| 回答太短 | 长度检查 | < 20 tokens 的回答删除 |
| 指令/回答重复 | SimHash 相似度 | 相似度 > 0.8 的去重 |
| 格式错误 | 正则匹配 | 缺少必要字段的删除 |
| 有害内容 | toxicity classifier | 有害分数 > 0.5 的删除 |
| 事实错误 | 用 GPT-4 做事实核查 | 置信度低的删除 |

### 多样性检查

确保数据覆盖了足够的任务类型：

```python
# 用分类器统计任务分布
task_distribution = {
    "reasoning": 0.15,
    "coding": 0.10,
    "writing": 0.20,
    "qa": 0.20,
    "translation": 0.05,
    "summarization": 0.10,
    "math": 0.05,
    "other": 0.15,
}
```

如果某个类型太少，针对性地补充。

## 4. 数据混合策略

### 不同类型数据的比例

| 数据来源 | 建议比例 | 效果 |
|----------|----------|------|
| 通用问答 | 30% | 基础对话能力 |
| 代码生成 | 15-20% | 逻辑推理 + 代码能力 |
| 写作/创意 | 15% | 多样性 + 表达力 |
| 数学推理 | 10% | CoT 推理能力 |
| 多轮对话 | 10-15% | 对话连贯性 |
| 角色扮演 | 5% | 风格适配 |
| 安全拒绝 | 5% | 安全对齐 |

### 多轮对话数据

单轮数据教会模型"一问一答"，多轮数据教会模型"对话"——记住上下文、追踪主题变化、在多轮中保持一致性：

```
{"messages": [
    {"role": "user", "content": "北京有哪些好玩的地方？"},
    {"role": "assistant", "content": "北京景点很多：故宫、长城、天坛..."},
    {"role": "user", "content": "那故宫怎么去？"},
    {"role": "assistant", "content": "故宫在天安门广场北侧，地铁1号线天安门东站..."},
    {"role": "user", "content": "门票多少钱？"}
]}
```

多轮数据让模型学会在后续回合中利用历史信息。

## 5. 数据量建议

| 微调阶段 | 最少数据量 | 推荐数据量 | 边际收益 |
|----------|-----------|-----------|---------|
| SFT | 1K (LIMA) | 10-50K | 100K+ 收益递减 |
| DPO | 1K | 5-20K | 50K+ 收益递减 |

**质量 > 数量** 的原则在微调数据中尤其重要——1000 条高质量数据 > 50000 条噪声数据。
