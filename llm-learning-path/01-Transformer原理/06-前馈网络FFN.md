# 前馈网络 FFN

FFN 看起来简单——就是一个两层 MLP——但它占据了大模型约 2/3 的参数量，且承担了与 Attention 完全不同的角色。

---

## 1. Attention 与 FFN 的分工

### 问题：Attention 不能做什么？

Attention 的运算是**线性加权**（加权求和）。它擅长的是"在哪些位置找信息并组合它们"。但它无法做**非线性的信息变换**（将信息从一种形式转化为另一种）。

如果一整层 Transformer 只有 Attention，那么它等价于一个线性变换——无论堆多少层，整体仍是线性的，表达能力极差。

### FFN 要解决什么

> 在每个 token 的表示上应用**非线性的逐位置变换**，将 Attention 收集到的上下文信息进行深度加工。

- **Attention** = "信息路由和聚合"（从其他位置收集信息）
- **FFN** = "信息处理与存储"（对收集到的信息做非线性变换）

两者配合：Attention 负责让正确的信息流到正确的位置，FFN 负责处理和存储这些信息。

---

## 2. FFN 的基本结构

$$\text{FFN}(x) = W_2 \cdot \sigma(W_1 \cdot x)$$

- $W_1$ 将维度从 $d_{model}$ 升到 $d_{ff}$（通常 2.7x~4x）→ 在高维空间有更大的表示容量
- 激活函数 $\sigma$ 引入非线性 → 允许复杂变换
- $W_2$ 将维度降回 $d_{model}$ → 回归残差流

**为什么需要升维再降维**：低维空间中很多信息模式是缠结在一起的，投影到高维后可以"解开"，处理完再压缩回来。这类似于 SVM 的核技巧思想。

---

## 3. 激活函数的演进

### ReLU → GELU → SwiGLU

| 激活函数 | 解决的问题 |
|----------|-----------|
| **ReLU** $\max(0, x)$ | 引入非线性。但负半区恒为 0 → 神经元可能"死掉"（永远输出 0） |
| **GELU** $x \cdot \Phi(x)$ | 平滑版 ReLU。负半区不完全为 0 → 保留了负信号的微小通路，训练更稳定 |
| **SwiGLU** $x \otimes \text{SiLU}(W_{gate} \cdot x)$ | 引入**门控机制**——一个分支产生信号，另一个控制信号流量 |

### SwiGLU 的结构

$$\text{SwiGLU}(x) = (W_3 x \otimes \text{SiLU}(W_1 x)) \cdot W_2$$

三个矩阵：
- $W_1$：Gate 投影，通过 SiLU 后生成 [0, 1] 区间的门控值
- $W_3$：Up 投影，生成实际的信号
- $W_2$：Down 投影，将结果降回 $d_{model}$

**门控的含义**：门控值接近 0 → 这个维度的信息被抑制；门控值接近 1 → 信息被放大。相当于每个维度有了一个自适应的"音量旋钮"。

### 为什么 SwiGLU 更好

- **非单调性**：SiLU 在负半区不完全为 0，允许细微的负信号通过
- **门控选择性**：模型自己学习哪些信息维度重要、哪些不重要
- 经验上训练收敛更快，下游任务效果更好

LLaMA、DeepSeek、Qwen、Mistral——所有现代大模型统一使用 SwiGLU。

## 4. FFN = 知识存储

### 证据

大量研究表明，FFN 层在大模型中扮演着**知识记忆库**的角色：

1. **事实编辑实验**：修改模型对特定事实（如"埃菲尔铁塔在___"）的知识时，主要变化发生在 FFN 的 $W_1$ 和 $W_2$ 权重中
2. **注意力可视化**：Attention 负责"找到命名实体"，FFN 负责"关联实体与属性"
3. **MoE 的验证**：MoE 模型就是把 FFN 扩展为多个专家，每个专家存储不同领域知识——专家选择（路由）就是"选择用哪个知识库"

### 推论：FFN 大小决定知识容量

- $d_{ff}$ 越大 → 可存储的模式越多
- 但参数也越多 → 训练和推理越贵
- MoE 通过稀疏激活打破了"知识容量 ↔ 计算成本"的矛盾：总 FFN 参数量巨大（知识多），但每 token 只激活一小部分（计算便宜）

---

## 5. 参数占比分析

以 LLaMA-7B 为例，单层参数分布：

| 组件 | 参数量 | 占比 |
|------|--------|------|
| Attention (QKV + Output) | ~67M | ~33% |
| FFN (Gate + Up + Down) | ~135M | ~67% |

**FFN 占了模型约 2/3 的参数**。这也解释了为什么模型微调时 LoRA 往往只加在 Attention 上（用较少的参数实现适配），但全量微调时 FFN 的变化才是知识获取的关键。

---

## 6. SwiGLU FFN 的维度选择

使用 SwiGLU 时有 3 个矩阵而非传统的 2 个。为了保持总参数量与旧版（$2 \times 4 \times d_{model}^2$）相近：

$$d_{ff} \approx \frac{8}{3} d_{model}$$

这样 $3 \times d_{model} \times d_{ff} \approx 8 d_{model}^2$，与原来的 $2 \times d_{model} \times 4 d_{model} = 8 d_{model}^2$ 持平。

| 模型 | $d_{model}$ | $d_{ff}$ | 比例 |
|------|-------------|----------|------|
| LLaMA-7B | 4096 | 11008 | ~2.69× |
| LLaMA-70B | 8192 | 28672 | ~3.5× |
| GPT-3 | 12288 | 49152 | 4× (GELU, 非 SwiGLU) |
