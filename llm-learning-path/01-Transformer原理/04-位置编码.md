# 位置编码

位置编码解决的致命问题：**Self-Attention 是置换等变的——打乱输入顺序，输出每个 token 的表示不变**（只是位置跟着打乱了）。"狗咬人"和"人咬狗"在 Attention 眼中每对 token 的关联分数完全相同。模型需要知道 token 的**顺序**。

---

## 1. 绝对位置编码：加法注入

### 方案

$$x_i = \text{Embed}(token_i) + \text{PosEncode}(i)$$

在 token embedding 上直接加上一个位置相关的向量。位置 i 永远加同样的向量。

### 正弦位置编码 (Sinusoidal)

原版 Transformer 的方案。使用不同频率的正弦/余弦函数对每个维度编码位置：

$$\text{PE}(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right)$$

$$\text{PE}(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

**设计精妙之处**：
- 不同维度对应不同频率 → 既区分远近（低频），又精细定位（高频）
- 三角函数有 $PE(pos+k) = f(PE(pos), PE(k))$ 的线性关系 → 模型可以学到相对位置
- 外推性：理论上可泛化到训练时未见过的长度

**实际限制**：虽然理论可外推，但实际训练后模型在超长序列上效果差——因为训练时没见过那么远的相对位置关系。

### 可学习位置编码 (Learned PE)

直接让模型学习一个位置 embedding 矩阵 `[max_len, d_model]`。GPT 和 BERT 使用。

**优点**：灵活，模型可以学到最优的位置表示。

**致命缺点**：无法外推。`max_len=512` 时第 513 个位置的 embedding 不存在，模型直接报错。

---

## 2. RoPE (旋转位置编码)：2023-2025 的绝对主流

### 解决的核心问题

绝对位置编码只是把位置信息"贴"在 token 上，不保证模型真的会用。更本质的问题是：**我们希望 Q 和 K 的内积天然地反映两个 token 之间的相对位置关系，而不是绝对位置。**

### 核心思想

不改变 Q 和 K 的模长，而是**将它们在高维空间中旋转一个与位置成正比的角**。旋转后，两个向量的内积只依赖于它们的**相对位置差**：

$$(R_m q)^T (R_n k) = q^T R_{n-m} k$$

- $m, n$ 是绝对位置
- $n-m$ 是相对位置
- 内积值只与相对位置有关，与绝对位置无关

这意味着**模型无需学习"位置 i 是什么"——它只需要学习"距离为 d 的两个 token 应该如何交互"**。这是更本质的位置建模。

### 旋转实现

将 d 维向量视为 d/2 个二维向量对，每个二维对旋转不同的角度：

$$\theta_i = base^{-2i/d}, \quad base = 10000$$

- 低维度旋转慢（低频）→ 对远距离也敏感
- 高维度旋转快（高频）→ 精细区分近距离

```python
def apply_rotary_emb(x, cos, sin):
    """x 的每两个维度一组做 2D 旋转"""
    d = x.shape[-1] // 2
    x_even, x_odd = x[..., ::2], x[..., 1::2]
    # 旋转变换
    x_rotated_even = x_even * cos - x_odd * sin
    x_rotated_odd  = x_even * sin + x_odd * cos
    return 交错拼接(x_rotated_even, x_rotated_odd)
```

### 为什么 RoPE 称霸

- **相对位置内化**：位置信息通过内积自动包含，无需显式加 position embedding
- **外推性好**：旋转操作的周期性天然支持训练时未见过的长度
- **实现高效**：Q 和 K 在计算前旋转一下即可，不改变原有的 Attention 结构
- LLaMA、Qwen、DeepSeek、Mistral、Gemma——所有主流开源大模型全部使用 RoPE

## 3. RoPE 的外推与扩展

### 问题：训练 4K，推理要 128K

RoPE 虽然理论可外推，但训练时频率分布只在 0-4096 的位置上优化过。到 128K 时，很多相对距离（如差 100000 个位置的两个 token）模型从未见过。

### 位置插值 (Position Interpolation)

最简单粗暴：把所有位置坐标按比例缩小。
```python
pos_new = pos_old * (4096 / 131072)  # 压缩回训练范围内
```
缺点：近距离的区分能力变差（原来差 1 的两个位置现在只差 0.031）。

### NTK-Aware Scaling

调整 RoPE 的 base 频率，让高频部分"分辨率"更高：
```python
base_new = base_old * (target_len / train_len) ** (d / (d - 2))
```
保留了局部分辨率，远距离也能外推。

### YaRN (Yet another RoPE extensioN)

NTK + 温度调整。对 Attention 的 softmax 输入除以一个温度因子，防止外推时的注意力分布过于平坦（远距离注意力分值都差不多，导致信息无法聚焦）。**YaRN 是目前外推效果最好的方法**，被 LLaMA 2 Long 等模型验证。

### Dynamic NTK

不在训练时固定 base，而是在推理时**根据实际序列长度动态调整**：
```python
if cur_len > train_len:
    scale = cur_len / train_len
    base = base * scale ** (d / (d - 2))
```
灵活且不需要重新训练。

## 4. NoPE：不需要位置编码？

2024 年的实验发现：对于 Decoder-Only 模型，**因果注意力掩码本身就可能蕴含了位置信息**（每个 token 只能看到左边 → 知道的 token 数量决定了位置）。去掉位置编码后模型在长度外推上表现更好，因为没有被训练长度范围限制住的位置表示。

代表：SmolLM3、Kimi K2 部分层。虽然目前还不是主流，但提示了位置编码可能不是必需的——这是 2025 年的一个活跃研究方向。
