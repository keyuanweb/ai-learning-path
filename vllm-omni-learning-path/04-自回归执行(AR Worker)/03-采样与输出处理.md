## 采样 —— 从概率到 Token

采样是将模型输出的 logits（每个可能 token 的分数）转换为具体 token 的过程。vLLM-Omni 复用了 vLLM 的采样器，但做了扩展。

### 采样参数（SamplingParams）

```python
class SamplingParams:
    temperature: float       # 温度（越高越随机）
    top_p: float             # nucleus sampling 阈值
    top_k: int               # 只从概率最高的 k 个中选
    max_tokens: int          # 最多生成多少个 token
    stop: list[str]          # 停止词
    output_kind: RequestOutputKind  # 输出模式
```

### 输出模式（RequestOutputKind）

```python
class RequestOutputKind:
    CUMULATIVE   # 每次返回之前所有 token（前端展示用）
    DELTA        # 每次只返回新增的 token（流式用）
    FINAL_ONLY   # 只返回最终结果（离线推理用）
```

对于非最后一个 Stage 的 AR 推理，通常使用 `FINAL_ONLY` 模式——中间的思维链不需要展示给用户，只需要最终结果。

[`output_processor.py`](../../code/vllm-omni/vllm_omni/engine/output_processor.py) 负责将 Stage 的原始输出（token ID 序列）转为用户可见的输出：

```python
class OutputProcessor:

```

## 多模态输出处理

[`mm_outputs.py`](../../code/vllm-omni/vllm_omni/engine/mm_outputs.py) 处理多模态输出（音频、图片、视频）：

### 音频输出

```python
# 声学特征 code → 音频波形
def decode_audio(codes, code2wav_model, sample_rate=24000):
    # 通过 Code2Wav 模型（如 HiFi-GAN、DiT）将 code 解码为波形
    waveform = code2wav_model.decode(codes)
    return waveform  # numpy array，shape = (samples,)
```

### 图片输出

```python
# VAE latent → 图片
def decode_image(latents, vae):
    # 通过 VAE Decoder 将潜空间表示转为像素
    image = vae.decode(latents)
    return image  # PIL Image
```

### 视频输出

```python
# 帧序列 → 视频
def decode_video(latent_frames, vae, fps=24):
    frames = [vae.decode(latent) for latent in latent_frames]
    return frames  # list[PIL Image]
```

## `output_modality.py` —— 输出模态标记

这个文件定义了输出模态枚举：

```python
class OutputModality:
    TEXT = "text"
    AUDIO = "audio"
    IMAGE = "image"
    VIDEO = "video"
    EMBEDDING = "embedding"
    LATENT = "latent"
```

每个 Stage 可以指定它输出什么模态，帮助输出处理器知道应该调用哪种解码器。
