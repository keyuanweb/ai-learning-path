## 多平台支持

vLLM-Omni 支持多种硬件平台。每个平台在 `platforms/` 下有独立的实现：

### 平台接口

[`interface.py`](../../code/vllm-omni/vllm_omni/platforms/interface.py) 定义了平台抽象：

```python
class OmniPlatform(ABC):
    @abstractmethod
    def get_platform_name(self) -> str: ...

    @abstractmethod
    def get_diffusion_packed_modules_mapping(self, model_class) -> dict: ...

    @abstractmethod
    def is_available(self) -> bool: ...
```

### 支持的平台

| 平台 | 硬件 | 目录 |
|------|------|------|
| **CUDA** | NVIDIA GPU | `cuda/` |
| **ROCm** | AMD GPU | `rocm/` |
| **NPU** | 华为昇腾 | `npu/` |
| **XPU** | Intel GPU | `xpu/` |
| **MUSA** | 摩尔线程 GPU | `musa/` |

### CUDA 平台

[`cuda/platform.py`](../../code/vllm-omni/vllm_omni/platforms/cuda/platform.py) —— 最完善的平台实现：

```python
class CudaPlatform(OmniPlatform):
    """
    NVIDIA GPU 平台：
    - 支持 FP8/INT8/INT4 量化
    - Flash Attention / CUTLASS
    - CUDA Graph 加速
    - NCCL 分布式通信
    """
```

### XPU（Intel GPU）平台

[`xpu/`](../../code/vllm-omni/vllm_omni/platforms/xpu/) —— Intel GPU 支持：

### ROCm（AMD GPU）平台

[`rocm/`](../../code/vllm-omni/vllm_omni/platforms/rocm/) —— AMD GPU 支持。

ROCm 平台相对简洁，AMD 的软件栈和 CUDA 比较接近。

## Sleep Mode —— 省显存特性

当某些 Stage 空闲时，可以将其模型权重从 GPU 卸载到 CPU，释放显存给其他 Stage 用：

```python
# OmniModelConfig 中
enable_sleep_mode: bool = False

# 当 enable_sleep_mode=True 时：
# - Stage 空闲超过阈值 → 卸载模型到 CPU
# - 新请求到达 → 快速加载回 GPU
# 适用于多 Stage 共享 GPU 的场景
```
