## 图像生成模型

### Flux —— 黑森林实验室的旗舰文生图

[`flux/`](../../code/vllm-omni/vllm_omni/diffusion/models/flux/)

```python
class FluxPipeline:
    """
    组件：
    - T5 Encoder：编码文本 prompt
    - FluxTransformer：DiT 去噪（~12B）
    - VAE：潜空间编解码
    """
```

关键文件：
- `pipeline_flux.py`：主 Pipeline（文生图）
- `pipeline_flux_kontext.py`：图像编辑 Pipeline
- `flux_transformer.py`：DiT Transformer
- `flux_pipeline_mixin.py`：共享逻辑

### Flux2 / Flux2 Klein

Flux2 是第二代 Flux，Klein 是蒸馏压缩版。它们使用 GGUF 格式加载。

### Qwen-Image —— 阿里的图像生成模型

[`qwen_image/`](../../code/vllm-omni/vllm_omni/diffusion/models/qwen_image/)

```python
# qwen_image 有多个 Pipeline：
- QwenImagePipeline          # 文生图
- QwenImageEditPipeline      # 图像编辑（如换背景）
- QwenImageEditPlusPipeline  # 增强版编辑
- QwenImageLayeredPipeline   # 分层生成
```

Qwen-Image 使用了特殊的 **CFG Parallel**（`cfg_parallel.py`），将条件/无条件路径分配到不同 GPU。

### Bagel —— 图文混合生成

[`bagel/`](../../code/vllm-omni/vllm_omni/diffusion/models/bagel/) 是一个特别的模型——它同时支持 AR 文本生成和 DiT 图像生成：

```
Bagel Pipeline:
  Stage 0 (AR): 理解 prompt，生成描述文本
  Stage 1 (Diffusion): 根据描述生成图片
```

它的 AR 部分在 `model_executor/models/bagel/`，扩散部分在 `diffusion/models/bagel/`。

## 视频生成模型

### Wan —— 阿里开源视频生成

[`wan2_2/`](../../code/vllm-omni/vllm_omni/diffusion/models/wan2_2/)

Wan 是视频生成领域的旗舰模型，Pipeline 种类最多：

```python
# 不同的视频生成模式
- Wan22Pipeline              # 文生视频（T2V）
- Wan22I2VPipeline           # 图生视频（I2V）
- Wan22S2VPipeline           # 语音驱动视频（S2V）
- Wan22VACEPipeline          # 视频编辑（VACE）
- WanT2VDMD2Pipeline         # DMD2 蒸馏加速
- WanI2VDMD2Pipeline         # I2V 蒸馏加速
```

Wan 的关键组件：
- `wan2_2_transformer.py`：DiT Transformer
- `wan2_2_vace_transformer.py`：VACE（编辑）Transformer
- `wan2_2_s2v_transformer.py`：语音驱动 Transformer
- `scheduling_wan_euler.py`：Wan 专用调度器

### LTX —— 轻量级视频生成

[`ltx2/`](../../code/vllm-omni/vllm_omni/diffusion/models/ltx2/)

LTX2 的特点是支持**两阶段级联**（`LTX2TwoStagesPipeline`）——第一阶段生成低分辨率视频，第二阶段做 latent 上采样（`pipeline_ltx2_latent_upsample.py`）。

### HunyuanVideo —— 腾讯混元视频

[`hunyuan_video/`](../../code/vllm-omni/vllm_omni/diffusion/models/hunyuan_video/) 支持文生视频和图生视频。

## 公共组件

### Schedulers（去噪调度器）

[`schedulers/`](../../code/vllm-omni/vllm_omni/diffusion/models/schedulers/)：

- `base.py`：调度器基类
- `scheduling_flow_unipc_multistep.py`：Flow Match + UniPC 多步求解器
- `scheduling_dmd2_euler.py`：DMD2 蒸馏 Euler 调度器

### T5 Encoder（文本编码器）

[`t5_encoder/`](../../code/vllm-omni/vllm_omni/diffusion/models/t5_encoder/)：

许多扩散模型使用 T5 来编码文本 prompt。vLLM-Omni 提供了 T5 和 T5-Gemma 两种编码器实现。

### Progress Bar

[`progress_bar.py`](../../code/vllm-omni/vllm_omni/diffusion/models/progress_bar.py) 提供了扩散去噪进度条（在终端显示"第 X/N 步"）。

### Diffusers Adapter

[`diffusers_adapter/`](../../code/vllm-omni/vllm_omni/diffusion/models/diffusers_adapter/) 提供了通用适配器，可以运行任意 HuggingFace Diffusers 格式的模型。
