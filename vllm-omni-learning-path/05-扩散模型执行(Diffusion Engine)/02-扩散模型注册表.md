# 02 · 扩散模型注册表：DiffusionModelRegistry

**源码**：[`code/vllm-omni/vllm_omni/diffusion/registry.py`](../../code/vllm-omni/vllm_omni/diffusion/registry.py)

## 注册表的作用

`DiffusionModelRegistry` 是一个大的"模型字典"，将模型架构名映射到实际的 Python 类：

```python
# 输入：模型架构字符串
# 输出：Python 类的位置
"FluxPipeline" → "vllm_omni.diffusion.models.flux.pipeline_flux.FluxPipeline"
"QwenImagePipeline" → "vllm_omni.diffusion.models.qwen_image.pipeline_qwen_image.QwenImagePipeline"
```

当用户指定 `--model black-forest-labs/FLUX.1-dev` 时，系统会读取模型的 `config.json`，找到 `architectures: ["FluxPipeline"]`，然后通过注册表找到对应的 Python 类并加载。

## 已注册的扩散模型

注册表中包含 40+ 个扩散模型/管线，涵盖：

| 类别 | 模型 | 注册名 |
|------|------|--------|
| 图像生成 | Flux, SD3, Qwen-Image, Z-Image, Ernie-Image, OmniGen2 等 | `FluxPipeline`, `QwenImagePipeline`, … |
| 图像编辑 | Qwen-Image Edit, LongCat Edit | `QwenImageEditPipeline`, … |
| 视频生成 | Wan, LTX2, HunyuanVideo, MagiHuman | `WanPipeline`, `LTX2Pipeline`, … |
| 音频生成 | Stable Audio, AudioX, OmniVoice, DreamID | `StableAudioPipeline`, `AudioXPipeline`, … |
| 图像理解 | InternVL-A1 | `InternVLAA1Pipeline` |
| 通用适配 | Diffusers Adapter（兼容任意 Diffusers 模型） | `DiffusersAdapterPipeline` |

## 注册模型的三元组

每个注册项包含三个信息：

```python
"FluxPipeline": (
    "flux",                   # mod_folder：在 models/ 下的子目录
    "pipeline_flux",          # mod_relname：Python 文件名
    "FluxPipeline",           # cls_name：类名
)
```

实际加载时：

```python
module_path = f"vllm_omni.diffusion.models.{mod_folder}.{mod_relname}"
module = importlib.import_module(module_path)
model_class = getattr(module, cls_name)
```

## 模型初始化流程

[`initialize_model()`](../../code/vllm-omni/vllm_omni/diffusion/registry.py#L284) 是加载扩散模型的统一入口：

```python
def initialize_model(od_config):
    # 1. 加载模型类
    model_class = DiffusionModelRegistry._try_load_model_cls(od_config.model_class_name)

    # 2. 准备量化配置
    _prepare_diffusion_quant_config(od_config, model_class)

    # 3. 实例化模型
    model = model_class(od_config=od_config)

    # 4. 配置 VAE（切片、分块、分布式）
    if hasattr(model, "vae"):
        model.vae.use_slicing = od_config.vae_use_slicing
        model.vae.use_tiling = od_config.vae_use_tiling

    # 5. 应用序列并行（如果启用）
    _apply_sequence_parallel_if_enabled(model, od_config)

    return model
```

## 前后处理函数注册

除了模型本身，注册表还管理**预处理函数**和**后处理函数**：

```python
_DIFFUSION_PRE_PROCESS_FUNCS = {
    "QwenImageEditPipeline": "get_qwen_image_edit_pre_process_func",
    "WanPipeline": "get_wan22_pre_process_func",
    ...
}

_DIFFUSION_POST_PROCESS_FUNCS = {
    "FluxPipeline": "get_flux_post_process_func",
    "WanPipeline": "get_wan22_post_process_func",
    ...
}
```

- **预处理**（pre_process）：在扩散推理之前，对用户输入做转换（如图片 resize、格式转换）
- **后处理**（post_process）：在扩散推理之后，对输出做处理（如帧插值、颜色校正、格式转换）

## DiffusersAdapter —— 通用适配器

[`diffusers_adapter/`](../../code/vllm-omni/vllm_omni/diffusion/models/diffusers_adapter/) 提供了一个**通用适配器**，可以运行任何 HuggingFace Diffusers 格式的模型，而不需要为每个模型写专门的 pipeline。

```python
class DiffusersAdapterPipeline:
    """
    通用扩散管线：
    - 自动加载 HF Diffusers 格式的 pipeline
    - 适配 vLLM-Omni 的批处理和调度机制
    - 支持序列并行、VAE 并行等优化
    """
```
