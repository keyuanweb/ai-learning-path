# 02 · 连接器实现：SHM / Mooncake / Yuanrong

**源码**：[`code/vllm-omni/vllm_omni/distributed/omni_connectors/connectors/`](../../code/vllm-omni/vllm_omni/distributed/omni_connectors/connectors/)

## 四种连接器对比

| 连接器 | 适用场景 | 传输方式 | 延迟 | 配置复杂度 |
|--------|---------|---------|------|-----------|
| **SHM** | 同机多 GPU | 共享内存 | 极低 | 简单 |
| **Mooncake Store** | 同机/跨机 | 分布式 KV Store | 低 | 中等 |
| **Mooncake Transfer Engine** | 跨机 | RDMA 高速传输 | 低 | 复杂 |
| **Yuanrong** | 跨机 | 自定义协议 | 中等 | 复杂 |

## SharedMemoryConnector —— 同机共享内存

[`shm_connector.py`](../../code/vllm-omni/vllm_omni/distributed/omni_connectors/connectors/shm_connector.py)

最常用、最简单的连接器。两个 Stage 在同一台机器上时，通过共享内存（Shared Memory）传输 KV Cache：

```python
class SharedMemoryConnector:
    """
    原理：
    1. Sender 在共享内存中分配一块空间
    2. Sender 将 KV Cache tensor 写入共享内存
    3. Sender 将共享内存的地址/key 发给 Receiver
    4. Receiver 通过地址/key 读取 KV Cache
    """
```

优点：零拷贝（GPU 显存间的直接传输），极低延迟

## MooncakeTransferEngineConnector —— 跨节点 RDMA

[`mooncake_transfer_engine_connector.py`](../../code/vllm-omni/vllm_omni/distributed/omni_connectors/connectors/mooncake_transfer_engine_connector.py)

Mooncake（源自月之暗面/Kimi）是一个高性能的 KV Cache 传输引擎，支持 RDMA：

```python
class MooncakeTransferEngineConnector:
    """
    使用 RDMA（Remote Direct Memory Access）跨节点传输：
    - 不需要 CPU 参与拷贝
    - 延迟接近本地传输
    - 需要 RDMA 网卡（如 InfiniBand）
    """
```

## MooncakeStoreConnector —— 分布式 KV 存储

[`mooncake_store_connector.py`](../../code/vllm-omni/vllm_omni/distributed/omni_connectors/connectors/mooncake_store_connector.py)

基于 Mooncake 的分布式 KV 存储方式：

```python
class MooncakeStoreConnector:
    """
    KV Cache 作为键值对存储在分布式存储中：
    - request_id → KV Cache
    - 支持任意接收方随时读取
    - 适合多对多的传输模式
    """
```

## 连接器基类

[`base.py`](../../code/vllm-omni/vllm_omni/distributed/omni_connectors/connectors/base.py) 定义了所有连接器的公共接口：

```python
class BaseOmniConnector(ABC):
    @abstractmethod
    def send_kv_cache(self, kv_blocks, target_info):
        """发送 KV Cache"""
        ...

    @abstractmethod
    def receive_kv_cache(self, transfer_info):
        """接收 KV Cache"""
        ...

    @abstractmethod
    def get_sender_info(self):
        """获取发送方信息（供接收方连接用）"""
        ...
```

## 如何选择连接器

```
是否同一台机器？
├─ 是 → SharedMemoryConnector（最快，零配置）
└─ 否 → 是否有 RDMA 网卡？
         ├─ 是 → MooncakeTransferEngineConnector（高速 RDMA）
         └─ 否 → MooncakeStoreConnector 或 YuanrongConnector
```
