这张图片是一张关于 **Agent Harness（智能体工程系统）** 的关系全景图，核心主题是 **“Agent 不是只有模型，而是 LLM 被一整套执行系统 (Harness) 包起来”**。它通过架构图、流程循环和模块速查表，系统性地解释了为什么构建一个稳定的 Agent 不能仅靠大模型本身，而必须依赖一套完整的工程化系统。

以下是图片内容的详细提取：

### 核心观点与背景
- **标题**：Agent Harness 关系全景图
- **副标题**：Agent 不是只有模型，而是 LLM 被一整套执行系统 (Harness) 包起来。
- **为什么需要 Harness**：列举了没有 Harness 时 Agent 会面临的 7 大问题：
    - **上下文混乱**：资料看错、抓错重点、遗漏规则。
    - **工具失控**：参数错、结果不可验、链路不稳定。
    - **权限过大**：读写执行权限混在一起，风险放大。
    - **环境不安全**：命令直跑、代码直改、影响真实环境。
    - **状态丢失**：任务中断后不知道做到哪一步。
    - **无人审查**：高风险动作无法拦截，容易翻车。
    - **无从观测**：问题定位困难、无法复盘改进。

### Agent Harness 架构总览 (11个模块)
图片中心展示了以 **LLM (理解-推理-决策-生成下一步计划)** 为核心的架构，周围环绕着 11 个关键支撑模块：

1. **Prompt 与指令**：给模型目标、规则、约束、输出格式。
2. **Context 上下文**：提供相关资料、代码、文档、历史对话、外部知识、工具结果等“模型需要知道的”（如 RAG 检索、规则与模板）。
3. **Tools 工具能力**：让模型能查询信息、操作系统、调用 API、执行业务（如内置工具搜索/计算、自定义工具 API/DB/脚本）。
4. **Function Call / MCP**：标准化的工具调用与协议层（Function Call: 模型调用函数；MCP: 统一协议接入外部工具；参数校验、类型约束、结果回传）。
5. **State 任务状态**：记录任务进度、当前计划、已完成步骤、待办事项、中间结果。
6. **Memory 记忆系统**：保存长期记忆与偏好，让 Agent 越用越懂你（如用户偏好、知识记忆、项目背景、经验沉淀）。
7. **Sandbox 沙箱执行环境**：把高风险执行放在隔离环境中运行（如命令执行隔离、代码执行隔离、文件系统快照）。
8. **Access Control 权限控制**：精细化权限，最小权限原则（如只读/写入/执行/管理分级、资源范围控制、凭证管理与临时授权）。
9. **Retry & Rollback 重试与回滚**：失败自动重试，或回滚到安全点重来（如自动重试指数退避/限定次数、回滚到上一个稳定状态、失败降级策略与兜底方案）。
10. **Observability 可观测性**：记录每一步发生了什么，辅助调试与优化（如工具调用日志、决策链路追踪、输入输出记录、失败原因归因、指标监控告警）。
11. **Human Review 人工审查**：关键动作前让人确认，降低风险（如写入/删除/发布/转账等高风险操作、敏感数据访问、重要决策/长任务阶段性确认）。

### Agent 执行流程 (典型循环)
图片下方展示了 Agent 工作的 7 步闭环流程：
1. **接收任务**：用户输入目标与约束。
2. **读取上下文**：检索资料、历史、规则、记忆。
3. **制定计划**：LLM 思考下一步要做什么。
4. **调用工具**：通过 Function Call/MCP 调用工具。
5. **执行与获取结果**：在 Sandbox 中执行，获取工具返回结果。
6. **更新状态**：保存结果，更新任务状态。
7. **检查是否完成**：未完成则循环，完成输出结果。

### 模块速查表与核心调用关系
- **模块速查表**：列出了上述 11 个模块分别解决什么问题（例如：Context 解决“模型看不全、看不对”的问题；Sandbox 解决“执行影响真实环境”的问题）。
- **谁调用谁 (核心调用关系)**：展示了 LLM 处于中心位置，它从 Context 获取信息，向 Tools 提供能力，读写 State/Memory，通过 Function Call/MCP 调用接口，受 Access Control 限制，在 Sandbox 中安全执行，必要时触发 Human Review，并通过 Observability 进行记录监控，失败时触发 Retry & Rollback。

### 总结与应用
- **一句话总结**：LLM 负责“思考”，Harness 负责“执行与兜底”。没有 Harness，Agent 容易翻车；有了 Harness，Agent 才能在真实世界里稳定、可控、可追踪地完成复杂任务。
- **适用场景**：
    - AI 编程助手（代码生成、改动、调试）
    - 企业知识助手（检索 + 执行 + 审批）
    - 自动化运营（多系统、多步骤协同）
    - 研发流程自动化（需求 -> 设计 -> 开发 -> 测试 -> 发布）
