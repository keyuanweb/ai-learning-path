# Agent Harness 八大模块速通

模型之外的执行系统，决定 Agent 能否稳定、可控、可上线

## 核心流程

用户目标 → 任务拆解与规划（LLM） → 调用工具/执行动作（Harness） → 观察结果/更新状态 → 循环迭代直至完成

## 八大模块详解

### 1. 上下文管理

- **解决什么问题**：把对的资料、规则、历史提供给模型，减少噪音和遗漏
- **典型例子**：项目代码/文档检索、用户需求与约束、历史对话与决策记录
- **没有它会怎样**：模型看错资料，答非所问；丢失关键信息，反复询问；长任务中上下文被冲掉

### 2. 工具注册

- **解决什么问题**：把外部能力标准化，提供给模型调用，提高可扩展性和可复用性
- **典型例子**：搜索/爬取/计算器、读写文件/数据库、调用内部 API /脚本
- **没有它会怎样**：模型只能靠自己编造；重复造轮子，效率低；无法连接真实数据源

### 3. MCP & Function Call

- **解决什么问题**：规范工具调用的输入输出格式，让模型能稳定、可验证地调用能力
- **典型例子**：MCP 服务连接外部系统、Function Call 调用 API、工具参数 Schema 校验
- **没有它会怎样**：参数不稳定，调用经常失败；模型猜参数，结果不可控；无法自动编排复杂工具链

### 4. 权限边界

- **解决什么问题**：控制模型能做什么、不能做什么，避免越权和高风险操作
- **典型例子**：只读/写入/执行分级、敏感文件/命令白名单、高风险操作需人工确认
- **没有它会怎样**：随意删改文件或数据；调用高风险接口；安全事故和数据泄露

### 5. Sandbox 执行环境

- **解决什么问题**：将代码、命令、文件操作放在隔离环境执行，保护真实系统安全
- **典型例子**：容器/虚拟机沙箱、文件系统隔离、网络访问受限
- **没有它会怎样**：命令直接在宿主机执行；误删系统文件或数据；破坏生产环境

### 6. 状态管理

- **解决什么问题**：记录任务进度、当前假设、已完成步骤和待办，支持长任务不中断
- **典型例子**：任务步骤 CheckList、当前上下文快照、中间结果缓存
- **没有它会怎样**：中断后无法继续；重复执行相同步骤；浪费时间和资源

### 7. Memory 记忆系统

- **解决什么问题**：保存长期知识、偏好、项目背景，让 Agent 越用越懂你
- **典型例子**：用户偏好/风格、项目架构与约定、历史决策与经验库
- **没有它会怎样**：每次都要重新解释；无法沉淀经验；个性化和持续性差

### 8. Human Review 人工审查

- **解决什么问题**：在关键节点让人确认，避免高风险操作和不可逆错误
- **典型例子**：写入/删除/发布前确认、大额操作/敏感数据处理、方案最终确认
- **没有它会怎样**：模型误判无法拦截；不可逆操作无法回滚；责任边界不清

## 增强能力（让 Agent 更稳、更可靠）

### 日志观测（Observability）

- **解决什么问题**：记录和追踪每一步决策、调用和结果，方便排查和优化
- **典型例子**：结构化日志、链路追踪、可视化面板、指标监控
- **没有它会怎样**：出问题时不知道在哪一步，难以复盘和定位根因

### Retry 重试机制

- **解决什么问题**：工具调用或网络异常时自动重试，提高成功率
- **典型例子**：指数退避重试、失败自动重试 N 次
- **没有它会怎样**：偶发错误导致任务失败，体验差且不稳定

### Rollback 回滚机制

- **解决什么问题**：在出错或不符合预期时，撤销已执行的高风险操作
- **典型例子**：文件版本回滚、数据库事务回滚、环境快照恢复
- **没有它会怎样**：错误操作不可逆，造成数据破坏或业务事故

### 评测与验证

- **解决什么问题**：验证 Agent 在真实任务上的效果，持续提升准确率
- **典型例子**：测试集评测、准确率/成功率指标
- **没有它会怎样**：无法量化效果，优化方向不明确

## 一句话总结

LLM 负责思考，Harness 负责执行与兜底。八大模块 + 四大增强 = 可用、可控、可持续的 Agent。

## 落地建议

- 先定义任务边界和权限
- 从小场景试点，逐步扩展工具
- 全程可观测，可回滚，可审查，才能上线
