# 02 · 配置系统：`EngineArgs` 与 `VllmConfig`

## EngineArgs

**源码**：[`code/vllm/vllm/engine/arg_utils.py`](../../code/vllm/vllm/engine/arg_utils.py)

约 2600 行的大 dataclass。**不要全读。** 只需知道：

- `EngineArgs` 聚合了所有可配置参数（模型路径、并行度、精度、KV 缓存、调度策略等）
- 关键方法 `create_engine_config()` 把离散参数组装成统一的 `VllmConfig` 对象
- 参数大致分这几组：

| 组 | 典型字段 |
|----|---------|
| 模型相关 | `model`, `tokenizer`, `dtype`, `max_model_len`, `quantization` |
| 并行相关 | `tensor_parallel_size`, `pipeline_parallel_size`, `data_parallel_size` |
| 调度相关 | `max_num_batched_tokens`, `max_num_seqs`, `enable_chunked_prefill` |
| KV 缓存 | `block_size`, `gpu_memory_utilization`, `swap_space` |
| 编译 | `compilation_mode`, `cudagraph_mode` |

## VllmConfig

**源码**：[`code/vllm/vllm/config/vllm.py`](../../code/vllm/vllm/config/vllm.py)

`VllmConfig` 是一个聚合类，它把 10+ 种子配置统一到一个对象里。扫一眼字段名即可：

| 子配置 | 类 | 文件 |
|--------|----|------|
| `model_config` | `ModelConfig` | `config/model.py` |
| `cache_config` | `CacheConfig` | `config/cache.py` |
| `parallel_config` | `ParallelConfig` | `config/parallel.py` |
| `scheduler_config` | `SchedulerConfig` | `config/scheduler.py` |
| `device_config` | `DeviceConfig` | `config/device.py` |
| `compilation_config` | `CompilationConfig` | `config/compilation.py` |
| `lora_config` | `LoRAConfig` | `config/lora.py` |
| `speculative_config` | `SpeculativeConfig` | `config/speculative.py` |

## 与 SamplingParams 的区别

这是新手最容易混淆的：

- **`EngineArgs`**：引擎级别，「模型怎么跑、用几块 GPU、KV 缓存多大」—— 创建引擎时设定
- **`SamplingParams`**：请求级别，「这个 prompt 用多高的 temperature、生成多少 token」—— 每次 `generate()` 时指定

## 阅读重点

- 扫一遍 `EngineArgs` 的字段列表（知道什么参数存在即可）
- 看 `create_engine_config()` 方法的签名
- 看 `VllmConfig` 的字段列表
