# 03 · 输入输出类型

## 输入类型

**源码**：[`code/vllm/vllm/inputs/`](../../code/vllm/vllm/inputs/)

看 `__init__.py` 了解导出清单。输入类型层级：

```
PromptType (联合类型)
├── SingletonPrompt
│   ├── str                    # 纯文本
│   ├── TextPrompt             # { text, multi_modal_data }
│   ├── TokensPrompt           # { prompt_token_ids }
│   └── EmbedsPrompt           # { embedding }
├── ExplicitEncoderDecoderPrompt  # encoder-decoder 模型
└── DataPrompt                 # 评分/embedding 模型
```

最常用的是 `str`（纯文本）和 `TextPrompt(text=..., multi_modal_data=...)`（带图片等）。

## 输出类型

**源码**：[`code/vllm/vllm/outputs.py`](../../code/vllm/vllm/outputs.py)

| 类 | 说明 |
|----|------|
| `RequestOutput` | 一次请求的完整结果：`request_id`, `prompt`, `outputs: list[CompletionOutput]`, `finished: bool` |
| `CompletionOutput` | 单个 completion：`index`, `text`, `token_ids`, `cumulative_logprob`, `finish_reason`, `stop_reason` |
| `PoolingRequestOutput` | pooling/embedding 请求结果 |
| `EmbeddingRequestOutput` | embedding 结果包装 |
| `ScoringRequestOutput` | 评分结果 |
| `ClassificationRequestOutput` | 分类结果 |

## 采样参数

**源码**：[`code/vllm/vllm/sampling_params.py`](../../code/vllm/vllm/sampling_params.py)

`SamplingParams` 是每次 `generate()` 调用时传入的请求级参数：

| 参数 | 说明 |
|------|------|
| `temperature` | 温度（>0 随机采样，0 贪婪） |
| `top_k`, `top_p` | top-k / top-p 采样 |
| `max_tokens` | 最大生成 token 数 |
| `stop`, `stop_token_ids` | 停用词 |
| `n` | 每个 prompt 生成几个 completion |
| `logprobs` | 是否返回 logprob |

## 阅读重点

- 知道输入类型的层级关系
- 记得 `RequestOutput.outputs` 是 `list[CompletionOutput]`（因为 n>1 时会生成多个）
- 理解 `EngineArgs` vs `SamplingParams` 的分工
