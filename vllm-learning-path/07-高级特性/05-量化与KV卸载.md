# 05 · 量化与 KV 缓存卸载

## 量化

**入口**：[`code/vllm/vllm/model_executor/layers/quantization/`](../../code/vllm/vllm/model_executor/layers/quantization/)

支持的量化方法：

| 方法 | 说明 |
|------|------|
| GPTQ | 4-bit 量化，group-wise |
| AWQ | Activation-aware Weight Quantization |
| FP8 | 8-bit 浮点量化（H100/H800 原生支持） |
| Marlin | 4-bit 量化，专为 GPU 优化 |
| BitsAndBytes | HuggingFace 的量化方案 |
| Compressed-Tensors | 稀疏 + 量化混合 |

量化通过 `QuantizeMethodBase` 接口集成到 `ColumnParallelLinear` 等层中。

## KV 缓存卸载

**入口**：[`code/vllm/vllm/v1/kv_offload/`](../../code/vllm/vllm/v1/kv_offload/)

当 GPU 显存不够存全部 KV 缓存时，把不常用的 KV 块换到 CPU 内存。

### 淘汰策略

| 策略 | 说明 |
|------|------|
| ARC | Adaptive Replacement Cache — 自适应平衡 recency 和 frequency |
| LRU | Least Recently Used — 优先淘汰最久未使用的块 |

### GPU 端的协作

`EngineCore.sleep(level)` / `wake_up(tags)` 方法可以：
- Level 0：暂停调度（不释放内存）
- Level 1：卸载模型权重到 CPU
- Level 2：卸载全部 GPU 内存中的内容

这支持弹性的 GPU 资源调度——引擎可以被休眠后恢复到其他 GPU。
