# 03 · 多模态

**入口目录**：[`code/vllm/vllm/multimodal/`](../../code/vllm/vllm/multimodal/)

## 处理流程

1. 用户传入 `TextPrompt(text="描述这张图", multi_modal_data={"image": img})`
2. `InputProcessor` 调用 `MultiModalRegistry` 找到匹配的 encoder
3. Encoder（如 CLIP）将图像处理成 embedding
4. Embedding 注回到 LLM 的 `inputs_embeds` — 替换 prompt 中图像占位 token 的 embedding
5. 后续 transformer 层正常处理（模型本身不感知输入来自文本还是图像）

## 支持的多模态类型

| 类型 | 典型模型 | Encoder |
|------|---------|---------|
| 图像 | Llava, Qwen2-VL, InternVL | CLIP / SigLIP |
| 视频 | Qwen2-VL | 逐帧 CLIP |
| 音频 | Whisper, Qwen-Audio | Whisper encoder |
