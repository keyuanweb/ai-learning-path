# 04 · 结构化输出

**入口目录**：[`code/vllm/vllm/v1/structured_output/`](../../code/vllm/vllm/v1/structured_output/)

## 原理

在某些步骤中，限制模型只能生成符合特定语法的 token。例如要求输出 JSON，则每步把不符合 JSON 语法的 token logit 置零，强制模型选了合法路径。

## 四个后端

| 后端 | 文件 | 说明 |
|------|------|------|
| XGrammar | `backend_xgrammar.py` | 默认后端，支持 JSON schema / regex |
| Outlines | `backend_outlines.py` | 基于 Outlines 库的 FSM 方法 |
| LM Format Enforcer | `backend_lm_format_enforcer.py` | 基于字符级过滤 |
| Guidance | `backend_guidance.py` | 基于 Guidance 库 |

## 在引擎中的位置

在 `EngineCore.step()` 中：
- 步骤 3：`scheduler.get_grammar_bitmask()` 计算一个 bitmask，标记哪些 token 在当前语法下合法
- 步骤 4：采样时使用这个 bitmask 过滤非法 token
