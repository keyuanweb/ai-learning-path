# 02 · 分布式并行

**入口目录**：[`code/vllm/vllm/distributed/`](../../code/vllm/vllm/distributed/)

## 五种并行度

| 并行类型 | 缩写 | 原理 |
|---------|------|------|
| Tensor Parallelism | TP | 权重矩阵在 GPU 间分片。`ColumnParallelLinear` / `RowParallelLinear` 实现 |
| Pipeline Parallelism | PP | 模型层在 GPU 间分片。`IntermediateTensors` 在 rank 间传递 |
| Data Parallelism | DP | 多个引擎实例，各自独立服务请求 |
| Context Parallelism | CP | 长上下文的注意力计算跨 GPU 分片 |
| Expert Parallelism | EP | MoE 的 expert 权重分布在不同 GPU 上 |

## DPCoordinator — 数据并行协调器

**源码**：[`code/vllm/vllm/v1/engine/coordinator.py`](../../code/vllm/vllm/v1/engine/coordinator.py)

在 DP>1 时，每个 GPU 运行一个独立的 `EngineCoreProc`。`DPCoordinator` 收集各 engine 的负载统计，决定新请求路由到哪个 engine。管理「请求波」（request waves）——全局同步的暂停/运行状态。

## KV 传输 — Prefill/Decode 分离式部署

**入口**：[`code/vllm/vllm/distributed/kv_transfer/`](../../code/vllm/vllm/distributed/kv_transfer/)

分离式（disaggregated）部署中，prefill 节点算完 KV 缓存后通过网络传给 decode 节点。`KVConnectorBase_V1` 在调度器和 worker 层面都集成了 KV 传输逻辑。

## TP 的关键数据流

以 `ColumnParallelLinear` 为例：
1. 每个 GPU 持有 1/TP 的输出权重列
2. Forward：各 GPU 独立计算自己的输出分片
3. 如果后面是 `RowParallelLinear`：输入可以直接是分片的（不需要 gather），输出再 all-reduce

这样相邻的 Column → Row 形成了高效的「分片-计算-规约」模式。
