## `Sampler(nn.Module)` — 采样流程

```python
class Sampler(nn.Module):
    def forward(self, logits, sampling_params, ...):
        # 1. 计算 logprobs（如果需要）
        logprobs = compute_logprobs(logits)

        # 2. 应用 bad words exclusion
        logits = apply_bad_words(logits, bad_words)

        # 3. 应用 logit processors
        logits = apply_min_p(logits, min_p)
        logits = apply_logit_bias(logits, logit_bias)

        # 4. 应用 penalties
        logits = apply_repetition_penalty(logits, output_token_ids, penalty)
        logits = apply_frequency_penalty(logits, output_token_ids, penalty)
        logits = apply_presence_penalty(logits, output_token_ids, penalty)

        # 5. 采样
        if temperature == 0:
            token_ids = greedy_sample(logits)
        else:
            logits = logits / temperature
            token_ids = top_k_top_p_sample(logits, top_k, top_p)

        # 6. 返回
        return SamplerOutput(sampled_token_ids, logprobs_tensors)
```

## 辅助文件

都在 [`code/vllm/vllm/v1/sample/ops/`](../../code/vllm/vllm/v1/sample/ops/) 下：

| 文件 | 说明 |
|------|------|
| `topk_topp_sampler.py` | top-k + top-p 采样内核 |
| `penalties.py` | repetition/frequency/presence penalties |
| `logprobs.py` | logprob 计算 |
| `bad_words.py` | 禁用词排除 |

## 可插拔 LogitsProcessor

在 [`code/vllm/vllm/v1/sample/logits_processor/`](../../code/vllm/vllm/v1/sample/logits_processor/) 下：

| 处理器 | 说明 |
|--------|------|
| `min_p.py` | 低于 max_prob * min_p 的 token 概率置零 |
| `logit_bias.py` | 给特定 token 加减分数 |

接口定义在 `interface.py` 中。

## 阅读重点

- 采样流程的六个步骤
- 区分 greedy（temperature=0，直接 argmax）和 stochastic（temperature>0，top-k/top-p）
- logits processors 是可插拔的（了解接口即可）
