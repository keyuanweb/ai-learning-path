# 02 · 模型注册与加载

## ModelRegistry — 模型注册/发现

**源码**：[`code/vllm/vllm/model_executor/models/registry.py`](../../code/vllm/vllm/model_executor/models/registry.py)

`ModelRegistry` 是一个单例，维护 HF 架构名 → vLLM 实现的映射：

```python
_TEXT_GENERATION_MODELS = {
    "LlamaForCausalLM": ("llama", "LlamaForCausalLM"),
    "Qwen2ForCausalLM": ("qwen2", "Qwen2ForCausalLM"),
    "Qwen3ForCausalLM": ("qwen3", "Qwen3ForCausalLM"),
    "MistralForCausalLM": ("mistral", "MistralForCausalLM"),
    # ... 100+ 条目
}
```

| 方法 | 说明 |
|------|------|
| `resolve_model_cls(architectures, model_config)` | 根据 model_config 中的 architectures 找到 vLLM 实现 |
| `is_pooling_model()` | 是否是 embedding/pooling 模型 |
| `is_multimodal_model()` | 是否支持多模态 |
| `is_hybrid_model()` | 是否混合注意力 + Mamba |

支持外部（out-of-tree）模型注册、通用 Transformers 后端、模型变体规范化（如 Qwen2.5 → Qwen2）。

## 模型加载流程

**入口**：[`code/vllm/vllm/model_executor/model_loader/__init__.py`](../../code/vllm/vllm/model_executor/model_loader/__init__.py)

```
get_model(vllm_config)
  │
  ├─ get_model_loader(load_config)
  │   根据 load_format 选择：
  │   "auto" → DefaultModelLoader     (HF safetensors / pt)
  │   "bitsandbytes" → BitsAndBytesModelLoader
  │   "gguf" → GGUFModelLoader
  │   "tensorizer" → TensorizerLoader (CoreWeave 流式)
  │   "sharded_state" → ShardedStateLoader
  │
  └─ loader.load_model()
       │
       ├─ initialize_model()
       │   在目标设备/dtype 上实例化 nn.Module
       │
       ├─ model.load_weights(weights)
       │   迭代权重文件，逐个应用到模型参数
       │   每个模型用自己的 stacked_params_mapping 做参数布局
       │
       └─ process_weights_after_loading()
           量化格式转换等后处理
```

## 阅读重点

- 跟一遍 `get_model()` → `load_model()` 的流程
- 知道不同 load_format 对应不同 loader
