## 模型通过 mixin 声明自己的能力

| Mixin | 能力 | 哪些模型实现了 |
|-------|------|-------------|
| `SupportsLoRA` | 支持 LoRA 适配器 | Llama, Qwen, Mistral 等大部分模型 |
| `SupportsPP` | 支持 Pipeline Parallelism | 大多数文本生成模型 |
| `SupportsEagle` | 支持 EAGLE 投机解码 | Llama 等 |
| `SupportsEagle3` | 支持 EAGLE3 投机解码 | Llama 等 |
| `SupportsMultiModal` | 多模态模型（图片/音频/视频输入）| Llava, Qwen2-VL 等 |
| `MixtureOfExperts` | MoE 模型（含 EPLB 支持）| Mixtral, DeepSeek-V2/V3 |
| `HasInnerState` | 有内部状态（非纯 Transformer）| Mamba, Jamba |
| `IsAttentionFree` | 无注意力机制 | Mamba-1 |
| `IsHybrid` | 混合注意力+Mamba | Jamba |
| `SupportsMRoPE` | 多维 RoPE | Qwen2-VL 等 |
| `SupportsTranscription` | 语音识别 | Whisper 等 |
| `SupportsEncoderCudaGraph` | vision encoder 支持 CUDA graph | 部分多模态模型 |

## 使用示例

添加新模型时，你只需继承对应的 mixin，就能自动获得相应功能。例如：

```python
class MyNewModelForCausalLM(nn.Module, SupportsLoRA, SupportsPP):
    # SupportsLoRA → 自动获得 LoRA 加载/合并能力
    # SupportsPP → 自动获得 Pipeline Parallelism 支持
    ...
```

## 阅读重点

- 了解有这些接口存在
- 添加新模型时回来查阅应该继承哪些 mixin
