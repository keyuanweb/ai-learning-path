# 03 · 关键层实现

## 并行感知的 Linear 层

**源码**：[`code/vllm/vllm/model_executor/layers/linear.py`](../../code/vllm/vllm/model_executor/layers/linear.py)

vLLM 的线性层不是普通的 `nn.Linear`，而是感知 Tensor Parallelism 的变体：

### ColumnParallelLinear — 列并行

在 output 维度上分片。TP=4 时，每个 GPU 只算 1/4 的输出通道。

```
输入: [batch, in_features] (每个 GPU 都有完整的输入)
权重: [in_features, out_features // 4] (每个 GPU 有 1/4)
输出: [batch, out_features // 4] (需要拼接才是完整输出)
```

### RowParallelLinear — 行并行

在 input 维度上分片。TP=4 时，每个 GPU 只接收 1/4 的输入通道。输出做 all-reduce 求和。

```
输入: [batch, in_features // 4] (每个 GPU 拿 1/4 输入)
权重: [in_features // 4, out_features] (每个 GPU 有 1/4 的行)
输出: [batch, out_features] (all-reduce 后每个 GPU 都有完整输出)
```

### QKVParallelLinear — Q/K/V 三合一

Q、K、V 三个投影的权重在 output 维度上拼接为一个矩阵，然后列并行分片。

```
HF 模型: q_proj, k_proj, v_proj (三个独立 weight，三次 kernel launch)
vLLM:    qkv_proj (一个大 weight，一次 kernel launch)
```

融合减少了 kernel launch 开销。

### MergedColumnParallelLinear — gate/up 二合一

SwiGLU MLP 中 gate_proj 和 up_proj 的融合。同样为了减少 kernel launch。
