# 01 · 符号地图：`vllm/__init__.py`

**源码**：[`code/vllm/vllm/__init__.py`](../../code/vllm/vllm/__init__.py)

## 为什么先读这个文件

这是 vLLM 的「符号地图」。花 10 分钟扫完 `MODULE_ATTRS` 字典（约 40 个导出符号），你就能快速定位任何类型在哪个文件。之后读代码时，看到不认识的类名，回来查这个文件就知道它在哪。

## 关键导出符号

| 导出符号 | 实际位置 | 用途 |
|----------|---------|------|
| `LLM` | `vllm.entrypoints.llm` | 离线推理主入口 |
| `LLMEngine` | `vllm.v1.engine.llm_engine` | 引擎前端（V1） |
| `AsyncLLM` | `vllm.v1.engine.async_llm` | 在线服务异步引擎 |

## 延迟加载机制

vLLM 使用 `__getattr__` 实现延迟加载（lazy import），避免 import vLLM 时立即初始化 CUDA 等重依赖。只有当你第一次访问某个符号时，对应模块才会被加载。

这就是为什么你可以在不 import torch 的情况下 `import vllm` —— 真正的重模块在第一次访问时才加载。
