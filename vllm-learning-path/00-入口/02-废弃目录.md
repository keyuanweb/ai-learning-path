# 02 · 废弃目录：`vllm/engine/`

**源码**：[`code/vllm/vllm/engine/`](../../code/vllm/vllm/engine/)

## 重要发现

打开 `vllm/engine/llm_engine.py`，你会看到里面只有一行：

```python
from vllm.v1.engine.llm_engine import LLMEngine as V1LLMEngine
LLMEngine = V1LLMEngine
```

`vllm/engine/` 目录下的所有文件都是 **历史遗留的薄层（shim）**，只做 re-export。真实逻辑全部在 `vllm/v1/` 下。

## 这意味着什么

- 你在其他地方看到 `from vllm.engine.llm_engine import LLMEngine` 时，直接跳转到 `vllm/v1/engine/llm_engine.py` 读实际代码
- `vllm/engine/arg_utils.py` 是例外，它包含真正的 `EngineArgs` 定义（这部分尚未迁移）
- vLLM 已完成 V0 → V1 的架构迁移，旧引擎代码已移除

## 阅读时间

5 分钟。理解「vllm/engine/ 是空壳」即可，所有源码阅读从 `vllm/v1/` 开始。
